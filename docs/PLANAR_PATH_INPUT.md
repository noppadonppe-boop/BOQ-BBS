# v0.66: กรอกมิติและมุมเพื่อสร้างแนวเหล็ก

เครื่องมือนี้สร้าง geometry และตำแหน่งของ Code 99 จากข้อมูลที่ผู้ใช้กรอก ไม่อ่านรูปดัดเป็นเหล็กอัตโนมัติ และไม่อนุมัติการผลิต ชนิดเหล็กสำหรับ BS และรายละเอียด ACI/โครงการยังต้องตรวจตามขั้นตอนเดิม BS8666 ขั้นต่ำเดิมและนโยบายคำนวณเดิมไม่เปลี่ยน

## เริ่มจากตารางต้นทาง

ที่หน้าสมาชิก > ตรวจเทียบ BBS จากแบบ กด **สร้าง BBS จากแถวนี้** ระบบนำ Mark, ขนาด nominal, เกรดตามที่พิมพ์ และจำนวนมาเปิดฟอร์ม โดยยังไม่คัดลอกยาวตัดหรือเดารัศมี รูปดัด และการเทียบ SD40 เป็นชนิดเหล็ก BS

ถ้าฐานจำนวนเป็นรวมทั้งสมาชิก ระบบหารด้วยจำนวนองค์ประกอบทั้งหมด ต้องลงตัวเป็นจำนวนเต็ม 1-2000 ต่อองค์ประกอบ โดยไม่ใช้จำนวนที่กรอง Zone/Floor ถ้ามี Mark/การจับคู่อยู่แล้ว ต้องทบทวนของเดิมก่อน ระบบไม่สร้างทับ ข้อมูลต้นทางที่เปลี่ยน/ถูกแทนที่หรือเปลี่ยนสมาชิกระหว่างกรอกจะไม่รับร่างเดิม

เมื่อกด **สร้าง BBS และจับคู่แถวต้นทาง** จะสร้างเหล็กที่ตรวจ geometry แล้วและจับคู่ด้วย ID จากนั้นกดบันทึกสมาชิก การจับคู่เพียงอย่างเดียวไม่รับรองรูปดัดหรือทำให้ตัวเลขตรงกับต้นฉบับ

## สร้างแนวจากมิติ

เปิดการวางเหล็กรายแท่งใน General Spec ก่อนใช้เครื่องมือ เลือกฐานมิติอย่างชัดเจน เครื่องมือไม่เลือกฐานจากยาวตัดที่พิมพ์

- **จุดตัดเส้นต่อแนวศูนย์กลาง**: ความยาวช่วงวัดระหว่างจุดตัดเสมือนของแนวศูนย์กลาง
- **ช่วงตรงระหว่างจุดสัมผัส**: ความยาวช่วงตรงก่อน/หลังส่วนโค้ง เครื่องมือคืนช่วงตัดเสมือนด้วยระยะสัมผัสจากรัศมีและมุม
- **จุดตัดเส้นต่อผิวนอกแต่ละช่วง**: มิติจากส่วนต่อผิวด้านนอกของแต่ละช่วง เป็นฐานเฉพาะที่ต้องตรวจต้นฉบับ มิติของมุมแหลมที่ใช้เส้นสัมผัส Figure 4 อาจใช้คนละฐาน ห้ามถือว่าเป็นสูตร Figure 4 โดยอัตโนมัติ

เลือก XY/XZ/YZ, มุมเริ่ม, ผิวนอก และรัศมีด้านใน กรอก 1-12 ช่วงตามลำดับจากปลายเริ่ม มุมเปลี่ยนแนวของช่วงแรกเป็นศูนย์ มุมบวกทวนเข็มในระนาบที่เลือก มุมลบตามเข็ม รองรับมุมเปลี่ยนแนวระหว่าง -179 และ 179 องศา แต่รูปที่สร้าง geometry ได้อาจยังไม่มีการตรวจ BS ที่รองรับครบ

กรอกพิกัดแม่แบบในพิกัดสมาชิกและตำแหน่งสุดท้ายตามแกนตั้งฉากกับระนาบ จำนวนมากกว่า1จะเรียงสม่ำเสมอ โดยไม่ใช้ค่าเริ่มต้น cover หรือค่ากลางช่วงแบบ legacy แท่งเดียวต้องกำหนดปลายช่วงเท่าพิกัดแม่แบบ ต้องไม่วางผิวเหล็กทับกัน ไม่ออกนอกคอนกรีต/ผ่านช่องเปิด และต้องมี cover พอ ตำแหน่งเฉพาะ/การหมุนเพิ่มเติมแก้ต่อได้ในเครื่องมือวางรายแท่ง

ภาพแสดงแนวศูนย์กลางและยาวตัดตามการปัดของโครงการ กด **ใช้แนวเหล็กที่กรอก** แล้วตรวจรูปก่อนใช้ชุดเหล็ก การแก้มิติในเครื่องมือที่ยังไม่กดใช้จะกันปุ่มบันทึกชุดเหล็กไว้ หากต้องแก้พิกัดด้วยมือ ให้ยกเลิกฐานมิติอย่างชัดเจนก่อน

สร้างใหม่จะล้างยาวตัด override, มิติอ้างอิง/มิติอิสระเดิม, หลักฐานตรวจการผลิต และการยืนยันมิติ/ตำแหน่ง พร้อมแทนตำแหน่งด้วยช่วงสม่ำเสมอที่กรอก ไม่ล้างเกรดหรือชนิด BS ที่ผู้ใช้เคยกำหนด แต่ต้องตรวจความเหมาะสมใหม่

## การเก็บและส่งออก

เก็บ `pathInput` version1 พร้อมจุดแม่แบบและตำแหน่งจริง ถ้าพิกัด/รัศมี/ผิวนอกไม่ตรงกับฐานมิติ จะไม่บันทึกจนสร้างใหม่หรือยกเลิกฐานมิติ ทำสำเนาสมาชิกจะเก็บข้อมูลมิติและเปลี่ยน ID ของเหล็ก/ตำแหน่ง แต่ไม่คัดลอกการจับคู่ต้นทางหรือการยืนยัน

Excel มี Path Input เก็บตัวเลขที่กรอกและความยาวช่วงเสมือนแยกกัน PDF A3/A1 มีฐานมิติและมุมในภาคผนวกตำแหน่งเดิม Frozen revision เก็บข้อมูลชุดเดิม และ Backup/Restore เก็บข้อมูลนี้พร้อมไฟล์ต้นทาง/ประวัติ

ตาราง Path Input และ Source BBS/Shapes Print ใช้ความกว้างที่ตรวจพิมพ์บน A3 ที่ 100% เพื่อรักษาขนาดกระดาษจริงใน Excel16.0 ที่ทดสอบ ไม่บังคับตารางทั้งโครงการให้เหลือหน้าเดียวและไม่เปลี่ยนปริมาณ การตั้งค่าเครื่องพิมพ์/ฟอนต์เครื่องอื่นต้องตรวจพิมพ์ก่อนส่งงาน

## ขอบเขตหลักฐานรอบนี้

ใช้ตาราง C1-100 เดิม และมิติรูป Mark309: 6400/203/700 กับมุม +7/-7 ใน **ขอบเขตคอนกรีตสมมติ 9000x1500x1500** สำหรับตรวจซอฟต์แวร์ รัศมีด้านใน50 และพิกัด24แท่งที่กรอกเป็นค่าของกรณีศึกษา ไม่ใช่รัศมี/ตำแหน่ง C1 ที่รับรอง เลือกฐานแนวศูนย์กลางอย่างชัดเจนได้ยาวตัด7325 ต่างจากต้นทาง7300 และยังไม่จับคู่ Mark4/5

ผ่าน1116 unit cases/68 files และ10เส้นทางจริงในระบบทดสอบ รวมการกันมิติที่ยังไม่ใช้, บันทึก/เปิดใหม่, Viewer/โครงการที่ไม่มีสิทธิ์, Frozen, ส่งออกและ Backup/Restore PDF จากแอป13หน้าและไฟล์ตรวจพิมพ์ Excel4หน้าเป็น A3 พร้อมตรวจภาพ กฎ/Auth/.env/Firebase config และต้นฉบับไม่เปลี่ยน ไม่มี deploy หรือคำขอไป production

นี่เป็นการตรวจฟังก์ชันเฉพาะรอบ ไม่ใช่การตรวจรับ12ข้อครบ ชุด GULF ที่สร้างเหล็กจริงทั้งหมด ฐานมิติ/รัศมี/ชนิด BS/ตำแหน่งติดตั้ง การอนุมัติวิศวกรรม เจ้าของงาน Issued ระบบ stock ฝั่งserver และ production ยังต้องดำเนินต่อ กฎและการ deploy เป็นหน้าที่ของผู้ใช้ตามคำสั่งล่าสุด
