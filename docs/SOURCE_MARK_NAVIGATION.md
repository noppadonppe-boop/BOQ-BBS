# เปิดตำแหน่ง Mark ในแบบต้นทาง — v0.95

ในแท็บตรวจเทียบ BBS จากแบบ หรือรายการเหล็กที่เลือก เปิด “ตำแหน่ง Mark … ในแบบ” แล้วเลือกชื่อไฟล์/ฉบับ/หน้า/#จุด ระบบเปิดหน้าและเน้นจุดที่บันทึกไว้ ทุกจุดต้องตรง Mark ของสมาชิกนี้ อยู่ในแบบฉบับปัจจุบัน และมี SHA256/จำนวนหน้าที่บันทึกไว้ ชื่อใกล้เคียงไม่ถูกจับคู่ให้อัตโนมัติ หากไม่มีจุด ให้เปิดแบบอ้างอิงและตรวจวางจุดเอง

ก่อนแสดงภาพ/จุดชี้ ระบบอ่านและตรวจ SHA256 ของไฟล์จริง เมื่อไม่ตรงจะซ่อนภาพและจุดเก่า หน้าเกินจำนวนหน้าจริงแสดงข้อผิดพลาด ไม่เปลี่ยนไปอีกหน้าให้เอง เมื่อฉบับไฟล์/เวอร์ชันจุดชี้/Mark เปลี่ยนต้องเลือกจากรายการปัจจุบันใหม่ การแก้จุดที่ยังไม่บันทึกระงับการเน้นจุดเดิม ผลสกัดข้อมูลที่กลับมาหลังขอบเขตแบบเปลี่ยนถูกทิ้ง การอ่านไฟล์ที่ค้างแจ้งหลัง 60 วินาทีและคืนเครื่องมือเลือกหน้า

การกดเปิดจุดเป็นการดูข้อมูล ไม่เพิ่มเหล็ก ไม่แก้จำนวน BOQ/BBS และไม่อนุมัติแบบ จุดอ้างอิงในฐานข้อมูลผูกด้วยข้อความ Mark; ไม่ใช่หลักฐานว่าตำแหน่งเหล็กทางกายภาพหรือการจับคู่เดิมหลังเปลี่ยนรายการเหล็กผ่านการตรวจแล้ว ยังต้องตรวจแบบ/รูปดัด/วัสดุและรับรองวิศวกรรม

ทดสอบด้วยไฟล์ B101 เดิม 4 หน้าและจุด QA01/QA02 ที่สร้างขึ้นเพื่อทดสอบซอฟต์แวร์เท่านั้น ไม่ใช่ตำแหน่งเหล็กจริงใน GULF ชุดแรกอ่านไฟล์ผ่าน Storage จริง ตรวจข้อมูลสมาชิก/ปริมาณ/จุดชี้/Frozen คงเดิม และทดสอบการเปลี่ยนเวอร์ชันจริง รอบเพิ่มเติมพบการอ่าน Storage ค้าง จึงทดสอบผลสกัดล่าช้า/compiled/mobile/hash โดยตอบไฟล์จำลองด้วย bytes เดิมอย่างเปิดเผย ยังไม่อ้างว่าบริการ Storage รอบล่าสุดฟื้นแล้ว ไม่ restart บริการหรือแก้ Rules
