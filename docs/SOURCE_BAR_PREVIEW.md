# Source-to-BBS candidate preview — v0.85

When creating a bar from an unassigned source-table row, the bar editor now shows the selected original bending crop beside the candidate geometry before applying it. It compares diameter/grade, count under the declared source basis, printed/calculated cut, cut difference, per-piece mass and group mass. Existing standard problems remain visible. Numbers matching does not approve shape, installation, grade mapping or engineering rules.

The preview is disposable and uses the same `applySourceBar` validation as the actual operation. It does not mutate the member or source rows, copy the printed cut into an override, map a material, add BOQ quantities or approve the member. Invalid coordinates, pending dimension/placement changes, changed source/member fingerprints, wrong bar identity and superseded sources withhold old calculated statistics and disable Apply. Pending or invalid geometry also withholds the candidate sketch.

Apply adds a Draft bar and maps only the selected source row; the user still saves the member separately. Existing confirmation-reset and Checked/Issued gates remain in place. A numerically different Draft is allowed for review; this does not relax the construction-release checks.
