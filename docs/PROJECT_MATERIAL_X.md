# วัสดุ X ของโครงการ — v0.77

ใน General Spec เพิ่มข้อกำหนดวัสดุ X แล้วระบุเกรด ขนาด nominal รัศมีด้านในขั้นต่ำ เส้นผ่านศูนย์กลาง mandrel มิติปลายขั้นต่ำ และเลขเอกสาร/Revision/หน้า พร้อมที่มาค่าและขอบเขต ใช้ได้สูงสุด40คู่เกรด/ขนาด ข้อมูลที่ยังว่าง ค่าที่ไม่เป็นบวก และคู่ซ้ำบันทึกไม่ได้ ช่อง mandrel ของกฎรุ่นนี้ต้องเท่ากับ2เท่าของรัศมีด้านในที่ระบุ เพื่อให้ตรงกับแบบจำลองดัดที่ใช้

เอกสารและฐานเป็นข้อความที่ผู้ใช้ระบุ ไม่ใช่หลักฐานว่าแอปตรวจหรืออนุมัติเอกสารนั้นแล้ว ต้องให้ผู้รับผิดชอบตรวจข้อกำหนดและกรณีอ้างอิงก่อนออก Issued อย่าใช้ค่าจากตัวอย่าง QA เป็นค่าผลิต SD40 จริง

ใน Mark ของ BBS เลือกชนิด X ด้วยตนเอง ระบบค้นเฉพาะเกรด/ขนาดที่ตรงกันใน Spec ของโครงการ ไม่เปลี่ยน SD40 เป็น R/T/B/S ไม่อนุมานกำลัง ความเหนียว หรือการเทียบมาตรฐาน วัสดุ R/T และชนิด BS เดิมยังใช้ Table3 เดิม ขนาดหรือเกรดที่ไม่ได้ระบุยังคงรอตรวจ การเพิ่มตารางไม่เปลี่ยนค่าหรือชนิดของ Mark ให้เอง

ขั้นต่ำ X ใช้ประกอบการตรวจรูปที่ระบบรองรับ โดยยังตรวจผิวนอก/ซี่บั้ง มิติทีละ5mm การปัดตัด25mm ช่วงตรงปลาย5d/10d และระยะระหว่างส่วนดัด4d ตามกฎเดิม มิติปลายที่กรอกเป็น overall end dimension ไม่ใช่ straight tail ขั้นรับรอง Code99 และข้อค้างของการปิดปลอก33/51ยังอยู่ Code67ยังรอการเทียบวัสดุ/วิธีจัดหา; ตารางนี้ไม่เปิดเส้นทางจัดหาเหล็กโค้งหรือแทนข้อกำหนด ACI

บันทึก Spec จะทำงานเป็นชุดและคืนสมาชิกทั้งหมดในโครงการเป็น Draft พร้อมล้างการยืนยันมิติ/ตำแหน่ง ตามขั้นตอนเดิม ฉบับ Frozen เก็บค่าที่ใช้เดิม รหัสคำนวณเพิ่ม `project-material-1.0` เฉพาะ Spec ที่มีตาราง X; Spec เดิมและผลตัดเดิมไม่ถูกเปลี่ยน การแก้ค่าภายในตารางมีผลต่อ digest ของ Spec และต้องตรวจรับใหม่

Excel มีแผ่น Project Material X เก็บค่าเป็นตัวเลขและข้อความแยกคอลัมน์พร้อมพื้นที่พิมพ์ A3 แบบ BBS และ BOQ PDF มีภาคผนวกข้อกำหนด X ที่จับไว้ในฉบับนั้น ตาราง BBS พื้นฐานแสดงชื่อมิติภายนอก เช่น A/(B) เมื่อมีมิติมาตรฐาน; กรณีไม่มี ใช้ virtual legs ที่ระบุว่าเป็น reference และไม่ตัดเหลือ8ช่วง คำอธิบายฐานตัดแสดงวิธีที่แถวคำนวณใช้จริง ไม่เหมารวมว่าเป็นแนวศูนย์กลาง

หลักฐานรอบนี้: 1350 unit cases/89files, 7เส้นทาง localล่าสุด รวม UIกรอก/ตรวจ/บันทึก, การคำนวณ/ตรึง, Viewer/โครงการไม่มีสิทธิ์, ไฟล์ Excel/PDFจริงจากแอป, Backup/RestoreและSHAไฟล์จริง, การเปลี่ยน Spec/คำขอล้าสมัย และการปฏิเสธตารางไม่ถูกต้อง Baseline Frozen ก่อนเพิ่ม X ตรวจแยกไว้และยังเรียกข้อมูลเดิมได้ ตรวจ Excelแบบอ่านอย่างเดียว3มุมมอง และ Microsoft Excel16.0อ่าน/คำนวณ/พิมพ์แผ่น X หนึ่งหน้าโดยไม่แก้ไฟล์ PDF A3จริง2หน้าถูก renderและตรวจภาพ/ข้อความหลังแก้ฐานตัดแล้ว

การสังเกตครั้งแรกจบก่อนการบันทึก UIเสร็จ และครั้งต่อไปรอข้อความ UIไม่สำเร็จ แต่ตรวจเซิร์ฟเวอร์ภายหลังพบงาน Complete แล้ว จึงตรวจต่อจากโครงการเดิมและยืนยันข้อมูลที่บันทึกจริง ไม่ restartบริการหรือสร้างโครงการแทนเพราะ timeout หลักฐานก่อนแก้ป้าย PDFยังเก็บอยู่

ไม่ได้ทดสอบ A1ของภาคผนวกใหม่นี้หรือชุดข้อมูล40กฎเต็มด้วยเครื่องพิมพ์จริง ไม่ใช่การตรวจรับวัสดุ GULF, BS/ACIทั้งหมด, owner/Issued/Production หรือครบข้อกำหนดเดิม12ข้อ Rules/config/Auth/.env และ BS/GULFต้นฉบับไม่เปลี่ยน ไม่ deployหรือเรียก Production ผู้ใช้กำหนดและ deploy Rulesเอง [รายงาน](../output/project-material-verification/DEVELOPMENT_REPORT.html)
