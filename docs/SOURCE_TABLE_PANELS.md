รุ่น v0.91 เพิ่มการรับหน้าใหม่ในตารางเดิมด้วยการเลือกและตรวจยืนยัน ดู [คู่มือหลายหน้า](SOURCE_TABLE_APPEND.md) ข้อจำกัดหลายหน้าในข้อความรุ่น v0.89 ด้านล่างเป็นประวัติเดิม ส่วนการรวมตารางอิสระหลายชื่อในหน้าเดียวกันยังไม่รองรับ

# ตาราง BBS ต่อเนื่องหลายชุดคอลัมน์ — v0.89

เปิด **ตรวจเทียบ BBS จากแบบ → อ่านตารางจาก PDF แล้วตรวจยืนยัน** เลือกไฟล์และหน้าที่มีตาราง ตัวอ่านรองรับตารางชื่อเดียวที่ต่อคอลัมน์ซ้าย–ขวาในหน้าเดียว เมื่อหัวคอลัมน์เหมือนกันและมี Total ร่วมเพียงแถวเดียว

แสดงภาพต้นฉบับแยกตามชุดคอลัมน์และเรียงข้อมูลจากบนลงล่างในชุดซ้าย ก่อนต่อชุดขวา ตัวอย่าง B-104 หน้า2 อ่านครบ40รายการ หัวคอลัมน์ซ้ำไม่ถือเป็นตารางอิสระ และไม่ใช้ผลรวมที่คำนวณแทน Total ที่พิมพ์

ก่อนรับข้อมูล ให้ตรวจทุกรายการ หน่วย mm/kg รูปดัด และฐานจำนวนเอง ต้องระบุที่มาและยืนยันก่อนรับ หากแทนตารางเดิม ต้องยืนยันการแทนและล้างการจับคู่เดิมด้วย ตารางหลายหน้าหรือตารางอิสระหลายชื่อยังต้องแยกกรอก หัวไม่ครบ Markซ้ำ ช่องอ่านไม่ชัด หรือหลายTotal จะรับข้อมูลไม่ได้

รูปดัดเสนอกรอบจากเส้นแบ่งแถวจริงใน PDF เมื่ออ่านได้ เพื่อไม่ติดข้อความแถวข้างเคียง การอ่านเส้นรองรับข้อมูล path ของ PDF.js5 ที่ตรวจแล้ว กรณีไม่มีเส้น/อ่านเส้นไม่ได้/รุ่นไม่รองรับ ใช้กรอบจากข้อความแบบเดิม ต้องตรวจและปรับกรอบด้วยมือ การมีภาพต้นฉบับไม่ได้ยืนยันรูปเหล็กที่แอปคำนวณ

ข้อมูลจากตัวอย่างคงค่าเกรด SD40 จำนวน ยาวตัด Kg/p และน้ำหนักตามต้นฉบับ ไม่จับคู่ BS type ไม่สร้างแนวเหล็ก ไม่เพิ่มปริมาณ BOQ/การตัด/Stock และไม่เปลี่ยนสถานะอนุมัติ Totalที่พิมพ์2908.61kg ต่างจากผลรวมแถว2908.59kg; คงความต่างไว้ให้ทบทวน ไม่มีการเติมน้ำหนักหรือกำหนด tolerance แทนผู้รับผิดชอบ

PDFที่มีรูปอ้างอิงหลายรายการใช้การบีบอัดPNG/streamแบบไม่สูญเสียข้อมูล เพื่อส่งออกได้ภายใต้Rulesเดิม ชุดทดสอบตรวจพิกเซลรูปที่ฝังทั้ง80รูปในA3/A1ตรงกับกรอบจากไฟล์ต้นฉบับ ไม่ลดจำนวนรูปหรือแก้Rulesเพื่อให้ไฟล์ผ่าน

ชุดตรวจใช้ไฟล์ B-104 จริงสำหรับตารางและรูปอ้างอิง ส่วนสมาชิกคานมีมิติ/จำนวนกล่องชั่วคราวสำหรับทดสอบเท่านั้น ยังไม่มีเรขาคณิตและเหล็กที่สร้างจากแบบจริง จึงไม่ใช่ BOQ/BBSพร้อมใช้ก่อสร้าง [รายงานและหลักฐาน](../output/source-panels-verification/DEVELOPMENT_REPORT.html)
