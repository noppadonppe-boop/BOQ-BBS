# Source Mark labels — v0.50

In a member's **แบบอ้างอิง** tab, select its current source drawing. Each saved pointer has a global number and the full Mark name. The overlay uses the visible page's actual aspect ratio, including PDF CropBox and rotation. Automatic placement keeps the label box inside that page; it can still cover source drawing content, so inspect it before export.

1. Select **วางป้าย** beside a pointer, then click where its label should appear on the drawing. This moves the label only. It does not move the original point or change bar counts, lengths, mass or member occurrences.
2. Select **ป้ายอัตโนมัติ** to reset only that label. Other manual labels remain stored.
3. Select **บันทึกตำแหน่ง**. Changes use the existing version check and reset the affected member's Draft/placement evidence. Save member edits first. Viewer and superseded-source authoring stay disabled.
4. Inspect overlapping labels and the source details underneath them. Manual overlaps are disclosed instead of silently moving a chosen position. Label placement has no engineering or installation approval effect.

The optional `annotations[].label = {x,y}` stores a normalized label center separately from the original normalized `x,y` source point. Both refer to the displayed, rotated page. Old records without `label` use automatic placement. Deleting a pointer removes its own label; resetting or changing source/page clears the selected placement tool so shifted indices cannot modify another pointer.

Actual XLSX exports append **Source Callouts** after the existing sheets. It retains full Member/Attachment/Mark identities, page/global pointer number, typed anchor coordinates and separate manual label coordinates. Numeric zero is preserved. Blank label coordinates mean automatic placement. These rows are references and do not add bar quantities. Coordinates are displayed to six decimals without changing their stored values.

**BBS + จุดชี้แบบต้นทาง A3** creates the saved working member's source-reference package. Source PDF sheets use numbered circles and a separate full-Mark legend. Saved manual centers map through the fitted visible source page; automatic circle placement is a separate paper layout from the browser's full-text labels. A chosen paper size can bound the circle within the source panel. The generator rejects circle-center separations below 7 mm so overlapping 6.2 mm circles cannot silently enter a completed file. This is a drawing legibility check, not a BS8666 fabrication tolerance. Reposition labels or split the package and export again.

Frozen snapshots retain the old point/label values even after later working edits. Backup retains both working annotations and old snapshots/files. Restore changes project and attachment/storage paths, retains member IDs within their new project namespace, preserves points/labels/bytes and resets approval/placement according to the existing restore policy.
