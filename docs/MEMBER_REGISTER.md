# ทะเบียนสมาชิกและตำแหน่งในโครงการ

เมนูทะเบียนสมาชิกรวม Foundation, Beam, Column, Slab, Wall และ Custom เพื่อค้นรายการและจัดการจำนวนในโครงการเดียวกัน หนึ่งแถวแทน occurrence ที่บันทึกจริง ไม่ใช่จำนวน Mark หรือตำแหน่งจุดชี้ในแบบ เลือกประเภท Zone ชั้น สมาชิก และสถานะ พร้อมค้น Member คำอธิบายหรือ Grid ได้ ยอดบนหัวตารางรวมรายการที่กรองพบทุกหน้า ตารางแสดงครั้งละ 50 ตำแหน่งและเปลี่ยนเป็นการ์ดบนมือถือ

กด Member เพื่อเปิดหน้ามิติและ BBS ของสมาชิก กดแก้ตำแหน่งเพื่อแก้ทุก occurrence ของสมาชิกนั้น รวมถึงตำแหน่งที่ตัวกรองปัจจุบันไม่ได้แสดง หน้าต่างแสดงจำนวน คอนกรีต แบบหล่อ และเหล็กที่กรอกก่อน–หลัง จำนวนต้องเป็นจำนวนเต็ม 1–100,000; มีอย่างน้อยหนึ่งตำแหน่งและไม่เกิน 1,000 ตำแหน่ง ข้อความ Zone/ชั้น/Grid ไม่เกิน 80 ตัวอักษร รหัสตำแหน่งเดิมคงเดิม ตำแหน่งใหม่ได้รหัสใหม่

บันทึกผ่านคำสั่ง saveMember เดิม พร้อมรุ่นโครงการที่เปิดหน้าต่างและรุ่นสมาชิก คำสั่งตรวจสิทธิ์และ Spec ปัจจุบันก่อนเขียน หากโครงการหรือสมาชิกเปลี่ยนต้องปิดหน้าต่างและเปิดข้อมูลใหม่ หากไม่ได้รับผลสำเร็จสามารถลองคำขอเดิมซ้ำด้วยรหัสเดิม โดยไม่บันทึกซ้ำเมื่อคำขอก่อนหน้าสำเร็จแล้ว

การแก้ตำแหน่งกลับสมาชิกเป็น Draft และยกเลิกการยืนยัน placement ตามขั้นตอนเดิม ไม่เปลี่ยนมิติ เส้นทางเหล็ก หรือจำนวนต่อ Mark ขอบเขตเดิมที่ระบุไม่มีเหล็กต้องยืนยันใหม่ในหน้าสมาชิก การตรวจมิติทางเรขาคณิตไม่ถูกยกเลิกเพียงเพราะเปลี่ยน occurrence แต่ผล review ที่ผูกรุ่น/input epoch ต้องตรวจใหม่ Frozen เก่าและไฟล์ที่ส่งออกแล้วคงฐานเดิม

ทะเบียนแสดงปริมาณเหล็กที่กรอกแยกจากคำว่า “รอ BBS” ข้อมูลครบไม่หมายถึงวิศวกรรมอนุมัติ ตัวกรองค้นหาและสถานะใช้ค้นรายการในทะเบียน ส่งออก BOQ/Excel ตาม Member/ประเภท/Zone/ชั้นผ่าน BOQ Summary ที่มีตัวเลือกขอบเขตชัดเจน ยังไม่มีการแก้หลายสมาชิกพร้อมกันหรือส่งออกตามข้อความค้นหา

หลักฐานทดสอบจากโครงการจำลอง 57 สมาชิก/114 occurrence และแอปที่ build แล้วอยู่ใน [รายงาน](../output/member-register-verification/DEVELOPMENT_REPORT.html) ใช้ Firebase จำลองเดิม ไม่มีการ deploy หรือเปลี่ยน Rules/Auth/config/.env ของผู้ใช้ ผลนี้ไม่ใช่การตรวจรับโครงการจริง BBS สำหรับก่อสร้าง หรือการเปิดสิทธิ์ Issued/Production
