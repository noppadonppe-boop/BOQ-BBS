# ตรวจพรีวิวฉบับก่อนส่งออก — v0.76

หน้าแบบส่งงาน หน้าสร้างไฟล์ส่งออก และหน้าชุดส่งตรวจอ่าน Snapshot ที่ตรวจ checksum แล้ว พร้อมตรวจทะเบียน Revision และสถานะจาก Firestore ในขณะโหลด หากเป็น Issued หรือฉบับที่มีประวัติออกแบบ ระบบตรวจหลักฐานออกฉบับเดิมก่อนแสดงข้อมูล หลักฐานที่หายหรือไม่ตรงกันทำให้เปิดพรีวิวไม่ได้ การโหลดนี้ไม่แก้ Snapshot ต้นทางหรือสร้างสิทธิ์อนุมัติใหม่

เลือก Revision แล้วเลือกสมาชิก/ประเภท/Zone/ชั้นเพื่อดูขอบเขตงาน ป้าย Frozen และ Draft ระบุ NOT FOR CONSTRUCTION ป้าย Issued ใช้ FOR CONSTRUCTION เมื่อมีหลักฐานที่ตรวจแล้ว ส่วน Superseded ระบุ NOT FOR CONSTRUCTION และใช้เพื่ออ้างอิงประวัติ ป้ายนี้ไม่แทนการตรวจรับทางวิศวกรรมหรือการรับเอกสารของเจ้าของงาน

หน้าสร้างไฟล์ตรึงตัวอย่างไว้จนเลือกฉบับหรือกดโหลดใหม่ เมื่อทะเบียนหรือสถานะเปลี่ยน รวมถึงการเปลี่ยนหลักฐานโดยยังใช้คำว่า Issued เหมือนเดิม ปุ่มสร้างไฟล์จะหยุดให้ตรวจตัวอย่างใหม่ คำขอจากพรีวิวผูก checksum ของสถานะ/หลักฐาน และตรวจซ้ำก่อนบันทึกงานส่งออก หากข้อมูลเปลี่ยนระหว่างเตรียม Snapshot จะไม่บันทึกงานหรือเปลี่ยนข้อมูลโครงการ อาจเหลือไฟล์ Snapshot ที่อัปโหลดไว้แต่ไม่มีงานอ้างถึง; งานนี้ยังไม่เพิ่มระบบเก็บกวาดไฟล์ดังกล่าว

หน้าชุดส่งตรวจโหลดข้อมูลใหม่เมื่อสถานะเปลี่ยน และสร้างไฟล์จากฉบับ/สถานะที่ดูอยู่เท่านั้น For Construction เลือกได้เฉพาะ Issued การเปลี่ยนบัญชีหรือโครงการล้างหน้าทำงานเดิม การเริ่มและปิดงานส่งออกยังตรวจหลักฐานตามกลไกเดิม

การตรวจในเครื่องผ่าน 1328 unit cases/87 files และ 6 เส้นทางกับ Firebase emulator รวมถึง Frozen จริง บัญชี Viewer ที่ได้รับสิทธิ์/โครงการที่ไม่ได้รับสิทธิ์ และคำขอที่ checksum สถานะไม่ตรง หน้าจอ build ตรวจทั้งคอมพิวเตอร์และมือถือ ตัวเลือกส่งออก 12 รูปแบบมี 10 รูปแบบพรีวิวได้ในตัวอย่างสมาชิก plain concrete; source-v9 และ A4 แสดงข้อจำกัดจากข้อมูลอ้างอิงที่ยังไม่ครบ ไม่ใช่การทดสอบส่งออก 12 ไฟล์จริง

กรณี Issued/Superseded และการเปลี่ยนทะเบียน/สถานะระหว่างโหลดหรือบันทึก ใช้ record/transaction doubles รวมถึงการตรวจหลักฐานออกฉบับจริงในโค้ด ยังไม่ได้สร้าง Issued จริงภายใต้ Rules ปัจจุบัน ไม่มี PDF/XLSX ใหม่หรือการตรวจพิมพ์ใหม่ในรอบนี้ ไม่มีการแก้/Deploy Rules, Auth, Firebase config หรือ .env และไม่มีคำขอไป Production ผู้ใช้กำหนดและ deploy Rules เอง การตรวจในแอปไม่ทดแทนการบังคับสิทธิ์บนเซิร์ฟเวอร์

ยังต้องตรวจรับ BS/ACI วัสดุ การปิดปลอก รูปดัด/ตำแหน่งเหล็กจาก GULF จริง และการใช้งาน Production ก่อนออก BBS สำหรับก่อสร้าง [รายงานพร้อมหลักฐาน](../output/published-preview-verification/DEVELOPMENT_REPORT.html)
