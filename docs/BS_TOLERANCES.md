# v0.37 — ผลวัดจริงรายชิ้น

เพิ่มการบันทึกผลวัดจริงรายชิ้นตาม [คู่มือผลวัด](FABRICATION_INSPECTIONS.md) เทียบกับช่วงอ้างอิงเดิมด้านล่างโดยไม่เปลี่ยนสูตร/นโยบายตัวเลข ข้อมูลขาดไม่ถือว่าผ่าน และมิติกำหนดเปลี่ยนแล้วเก็บผลเก่าให้ตรวจใหม่ การเทียบมิติอิสระเป็นสมการเท่านั้น ยังไม่มีเกณฑ์ผลต่างที่อนุมัติ ไม่ปิดข้อ9ทั้งข้อหรือปรับยาวตัด/BOQอัตโนมัติ ผลหนึ่งชิ้นไม่เป็นผลทั้งล็อตและไม่เปิด Issued/Production

# ค่าคลาดเคลื่อนอ้างอิงของเหล็ก

เปิดสมาชิก → เลือก Mark → เปิด **ค่าคลาดเคลื่อนอ้างอิง BS Table 4** ในรายละเอียด หรือเปิดในหน้าต่างแก้ Mark ได้ ตารางใช้ค่ากำหนดจากชุดข้อมูลที่กำลังดู และระบุมิติอิสระด้วยวงเล็บ บนมือถือเลื่อนตารางแนวนอนเพื่อดูครบทุกช่อง

ที่มาเป็นไฟล์ที่ผู้ใช้กำหนด `Referrence/BS 8666.pdf`: BS8666:2000 รวม Amendments1/2 ข้อ9/Table4 หน้า13 (PDFหน้า17) SHA256 `9c6fa5d0bafd0a8761f14d1611c582d5db7d89710eaaf0910b5dc7c493e0cb43` ไม่ใช่การเปลี่ยนไปใช้มาตรฐานฉบับใหม่ รุ่นอ้างอิงคือ `bs8666-2000-table4-reference-1.0`

| กระบวนการ / ขนาดมิติ | เพิ่ม mm | ลด mm |
| --- | --- | --- |
| ตัดความยาว | 25 | 25 |
| ดัด มิติไม่เกิน1,000mm | 5 | 5 |
| ดัด มิติมากกว่า1,000ถึง2,000mm | 5 | 10 |
| ดัด มิติมากกว่า2,000mm | 5 | 25 |

ค่า1,000และ2,000ใช้ช่วงก่อนหน้า ไม่ปัดค่ากำหนดก่อนเลือกช่วง มิตินอกที่ geometry/สูตรรองรับเท่านั้นจะแสดงเป็นมิติดัด Code99/พิกัด/Lxx/มิติที่เสนอไม่ได้กลายเป็นมิติดัดที่รับรอง รัศมีไม่ได้ถูกเพิ่มเป็นมิติดัด A–E โดยอัตโนมัติ

Excel ที่ส่งออกใหม่เพิ่ม **BS Tolerances** เมื่อโครงการเปิดขั้นต่ำ BS2000 ชีตเก็บค่ากำหนด/เพิ่ม/ลด/ขอบล่าง/ขอบบนและข้อจำกัด ยาวตัดเชื่อมกับชีต BBS ส่วนมิตินอกคงตาม Snapshot สูตรช่วงคำนวณจากค่าที่แสดง การแก้ Excel ไม่เปลี่ยน geometry/มิติอิสระในแอปและไม่เป็นการตรวจรับ

ตารางตัด/ดัด A4 ที่ส่งออกใหม่มีภาคผนวกอ้างอิงเดียวกัน ระบุเลขตาราง สมาชิก และ Mark พร้อมขอบเขตการใช้งาน การแบ่งหน้ารวมภาคผนวกมีขีดจำกัด500แผ่น ไฟล์เดิมที่สร้างเสร็จแล้วดาวน์โหลดไบต์เดิม ส่วน Revision ที่ตรึงไว้ใช้จำนวนและยาวตัดจาก Revision ไม่ใช้ Working ล่าสุด

ช่วงเหล่านี้เป็นค่าอ้างอิงรายมิติ ไม่ใช่ผลวัดเหล็กที่ผลิตจริง และยังไม่ได้คำนวณค่าคลาดเคลื่อนสะสม การรับค่าเผื่อของมิติอิสระ หรือปรับพิกัด/ยาวตัด/น้ำหนัก ระบบแจ้งเมื่อค่าปลายต่ำกว่า Table3 ที่ขอบล่าง แต่ไม่อนุมัติหรือปฏิเสธการผลิตแทนผู้ตรวจ กรณีระบุยาวตัดเอง/ข้อมูลยังผิด/ค่ามากเกินความละเอียดจะแสดงข้อจำกัด ไม่มีช่วงที่คำนวณไม่ได้แทนด้วยค่าปลอม

ดูหลักฐานใน `output/tolerance-verification/DEVELOPMENT_REPORT.html` ยังต้องตรวจรับวิศวกรรม/ACI/กฎและกรณีอ้างอิงครบ การพิมพ์ Excel จริง รูปแบบเจ้าของงาน และระบบ Production ผู้ใช้กำหนดและ deploy Rules เอง
