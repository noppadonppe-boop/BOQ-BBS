# ดูตำแหน่ง Mark ในแปลนและรูปตัด — v0.54

หน้า Workspace และ Frozen preview แสดงเส้นเหล็กของทุก Mark และแบ่งเส้นชี้เป็นชุดละ 7 Mark เพื่ออ่านชื่อเต็มได้ คลิก “ชุดก่อนหน้า/ชุดถัดไป” หรือค้นหาชื่อ Mark แล้วเลือกจากรายการใต้รูปได้ด้วยเมาส์และแป้นพิมพ์

เลือก Mark จากตาราง BBS จะเปิดชุดที่มี Mark นั้นให้ทันที รวมถึงการเลือก Mark เดิมซ้ำหลังค้นหาชื่ออื่น การเลือกจากเส้นเหล็กจะเปิดชุดของเส้นนั้น การค้นหากรองเฉพาะรายการชื่อและเส้นชี้ โดยเส้นเหล็กทั้งหมดอยู่ในรูปเสมอ

เลือก “สองรูป”, “แปลน” หรือ “รูปตัด” และเลื่อนภาพในแนวนอนบนจอแคบได้ ชื่อที่ยาวจะแสดงครบในรูปและรายการใต้รูป รายการระบุว่า Mark นั้นตัดผ่าน A-A ณค่า Y ที่แสดงหรือไม่ ถ้าไม่ตัดผ่าน จะแสดงชื่อสีเทาในรูปตัดและไม่มีเส้นชี้ไปยังตำแหน่งที่ไม่มีเหล็ก

เครื่องมือดูรูปไม่แก้มิติ จำนวนเหล็ก การยืนยันตำแหน่ง สถานะสมาชิก หรือปริมาณ BOQ ผู้ใช้อ่านอย่างเดียวใช้เครื่องมือดูรูปได้ แต่ยังแก้ Mark หรือบันทึกสมาชิกไม่ได้ Frozen preview คงใช้ข้อมูลเดิมที่ตรึงไว้

การแบ่งชุดบนหน้าจอไม่เปลี่ยนการแบ่งหน้าของ PDF เดิม: รูปแบบ schedule-v1 ใช้ 5 Mark/แผ่น A3 และ 12 Mark/แผ่น A1 รอบนี้ตรวจไฟล์จากระบบจริงด้วยข้อมูลจำลอง24 Mark ได้5แผ่น A3 และ2แผ่น A1 ทั้งหมดมีชื่อครบและคงข้อมูล Frozen เดิม

ข้อมูลทดสอบนี้ไม่ใช่การสร้างเหล็กจากแบบ GULF หรือกรณีวิศวกรรมที่รับรองแล้ว Mark32ตัวอักษรเป็นการทดสอบการแสดงผล และยังมีปัญหามาตรฐาน BS เรื่องความยาวชื่อ Mark พร้อมการยืนยันมิติที่ยังค้าง ระบบยังไม่พร้อมออก Issued ใช้ก่อสร้าง และไม่มีการแก้หรือ deploy Rules ของผู้ใช้
