# Local QA Storage runtime recovery — 2026-10-14

This tooling is for the local demo-boq-v041 QA environment only. It does not ship with the Vite application and does not change Rules, Auth application code, the API, Cloud Functions or Production deployment.

The installed firebase-tools14.27.0 Storage runtime attempts JSON.parse on a complete stdout data chunk. The observed log contains a permit response and a Firestore-fetch response in the same chunk, which its catch branch logs and drops. The test executes the actual installed runtime source with synthetic process streams and reproduces the loss. The adapter uses Node readline to handle complete lines across combined/fragmented chunks without changing permit decisions or callback IDs. It refuses other versions/listener layouts and changes only the loaded local module; node_modules files are unchanged. [Node readline reference](https://nodejs.org/api/readline.html).
