# v0.41 — เลือกชุดข้อมูลก่อนส่งออก

ในหน้าแบบส่งงาน กด **สร้างไฟล์ส่งออก** เพื่อใช้ revision และตัวกรองที่กำลังดู หรือกด **ส่งออกข้อมูลทำงาน** เพื่อเริ่มจาก Draft ปัจจุบัน

1. เลือกข้อมูลทำงานหรือ revision ที่ตรึงไว้ ข้อมูลตัวอย่างคงไว้จนเลือกฉบับอื่นหรือกดโหลดใหม่
2. เลือกสมาชิก ประเภท Zone และชั้น ตัวกรองที่ขัดกันหรือไม่พบข้อมูลจะหยุดการส่งออก ไม่เปลี่ยนเป็นทั้งโครงการ
3. เลือกรูปแบบ BBS, BBS พร้อมแบบต้นทาง, Excel, BOQ PDF หรือ A4 ตารางตัด/ดัด รูปแบบรายละเอียดเดิมยังเลือกได้
4. ตรวจจำนวนองค์ประกอบจริง ปริมาณรวม เหล็กแยกขนาด และทะเบียนเลขแบบ แล้วสร้างไฟล์

BBS เลือก A3/A1 ได้ ตารางตัด/ดัดใช้ A4 ส่วน BOQ PDF และหน้าพิมพ์ใน Excel ใช้ A3 ตามตัวสร้างไฟล์ที่มีอยู่ ขนาดที่แสดงจึงตรงกับไฟล์จริง

ข้อมูลทำงานผูกกับรุ่นโครงการที่เปิดดู หากข้อมูลเปลี่ยนจะหยุดและให้โหลดข้อมูลล่าสุด โดยเก็บตัวกรองเดิมไว้ ส่วน revision ผูกกับ checksum และสถานะ ใช้มิติ ปริมาณต่อหน่วย และกรอบชื่อแบบใน snapshot เดิม แม้ข้อมูลทำงานจะเปลี่ยนแล้ว การเปลี่ยนสถานะเป็น Superseded ระหว่างเปิดตัวอย่างต้องโหลดอีกครั้ง

ตัวคำสั่งตรวจรุ่น/checksum/สถานะก่อนอ่านหรืออัปโหลด snapshot ใหม่ และยังตรวจการเปลี่ยนข้อมูล/ประวัติใน transaction เดิม Exact retry ของคำขอที่สำเร็จแล้วคืนงานเดิมได้แม้ข้อมูลทำงานเปลี่ยน ไม่มีการแก้ไฟล์ย้อนหลัง

การอ่าน revision เกิน20วินาทีแสดงปัญหาและปุ่มโหลดใหม่ การตรวจหน้าจอเป็นการตรวจ input ที่รองรับเท่านั้น การอ่านแบบต้นทาง ตรวจ bytes/checksum และการสร้าง/ตรวจไฟล์จริงยังเกิดในงานส่งออก ข้อจำกัดจำนวนหน้าและรูปแบบรายละเอียดเดิมยังใช้ตามตัวสร้างไฟล์

Draft/Frozen/Superseded ยังคง NOT FOR CONSTRUCTION และ Issued ยังปิด รอผู้รับผิดชอบตรวจรับกฎวิศวกรรม ไม่ได้เปลี่ยนสูตร BS/ACI หรือสิทธิ์โครงการ User-owned Rules, Auth, `.env` จริง และการ deploy คงเดิม

การตรวจ v0.41 ใช้ backend ทดสอบแยกจาก checkpoint เดิม มี Auth/Firestore สำหรับ QA และ Storage เฉพาะไฟล์ต้นทางหนึ่งไฟล์ที่ตรวจ byte hash แล้ว จึงไม่ใช่การตรวจ recovery ทั้งฐานข้อมูล ตัวช่วยทดสอบจัดข้อความตอบของ Storage Rules ตาม newline เพื่อแก้ปัญหาการรวม/แบ่ง chunk ของเครื่องมือ Firebase CLI โดยไม่เปลี่ยนผลอนุญาต ปฏิเสธ หรือเนื้อหา Rules และไม่แก้ dependency directories บริการเดิมไม่ได้ถูกหยุดหรือแก้ไข
