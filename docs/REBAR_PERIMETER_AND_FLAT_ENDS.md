# v0.67: เหล็กรอบหน้าตัดและระยะหุ้มปลายตัดเรียบ

เพิ่มเครื่องมือจัดตำแหน่งรอบกรอบสี่เหลี่ยม การหมุนรูปแม่แบบ และวิธีตรวจระยะหุ้มที่ปลายตัดเรียบแบบเปิดใช้รายโครงการ ใช้เพื่อกรอกและตรวจร่างจากแบบ ไม่ใช่ตัวออกแบบหรือรับรองเหล็ก BS/ACI

## วิธีใช้

1. ใน General Spec เปิดการวางรายแท่ง หากต้องตรวจผิวปลายตัดเรียบ ให้เลือก **ปลายตัดเรียบ · ตรวจผิวและทิศของปลาย** แล้วบันทึกข้อกำหนด Draft การเปลี่ยนนี้เก็บนโยบาย `rebar-flat-ends-1.0` และเพิ่ม ID ของตัวตรวจในข้อมูล Frozen วิธีเดิมยังเป็นค่าเริ่มต้น
2. สร้างรูปเหล็กจากมิติและมุม เลือกฐานมิติจากแบบและระบุรัศมี/ผิวนอก หมุนรูปแม่แบบรอบแกนสมาชิก X แล้ว Y แล้ว Z ได้ ภาพในเครื่องมือแสดงระนาบก่อนหมุน ส่วนพิกัด แปลน/รูปตัดและ3D ใช้รูปหลังหมุนจริง
3. ในตำแหน่งรายแท่ง โหลดตำแหน่งที่ใช้อยู่ เปิด **จัดแท่งรอบหน้าตัดสี่เหลี่ยม** กรอก XY/XZ/YZ จุดเริ่มและปลายกรอบเป็นพิกัดศูนย์กลางเหล็ก จำนวนสองด้านรวมจุดมุม และที่มา
4. เลือกมุมของด้านและของมุมกรอบแยกกัน มุมหมุนรอบแกนตั้งฉากของสมาชิก ไม่ได้กำหนดให้เหล็กหันเข้าด้านใดโดยอัตโนมัติ มุมกรอบจุดแรกต้อง0° เพราะใช้ทิศแม่แบบ หากต้องสลับระดับ/offset ตามลำดับแท่งให้กรอกอย่างชัดเจน
5. กดจัดตำแหน่งรอบกรอบ แล้วตรวจ/ใช้ตำแหน่งรายแท่งก่อนใช้ชุดเหล็กและบันทึกสมาชิก มุมทั้งสี่นับครั้งเดียว จำนวนรวมคือ2×(จำนวนด้านแรก+จำนวนด้านที่สอง)-4 จำกัด2000แท่งต่อMark

ข้อมูลตำแหน่ง/มิติที่ยังไม่ได้ใช้จะกันการบันทึกชุดเหล็กทันที โหลดตำแหน่งที่ใช้เพื่อยกเลิกการแก้ในฟอร์ม เมื่อแก้รูปแม่แบบที่มีตำแหน่งเฉพาะอยู่แล้ว ค่าเริ่มต้น **คงตำแหน่งรายแท่งที่ใช้** จะรักษา anchor/pivot/offset/rotation และจำนวน หากต้องแทนด้วยช่วงสม่ำเสมอให้ยกเลิกตัวเลือกนี้อย่างชัดเจน

## ขอบเขตตัวตรวจปลายตัด

ตรวจหน้าตัดปลายตั้งฉากกับแนวเหล็ก โดยใช้รัศมีด้านข้างครบและระยะหุ้มของผิวคอนกรีตที่รับผิดชอบ ปลายเอียงมีพื้นที่ฉายของหน้าตัด ไม่ได้ตัดรัศมีออกทุกทิศ

ใช้กับปลายตรงของ straight/L/U/polyline ที่ช่วงปลายยาวพอ ส่วนโค้งภายในยังใช้ขอบเขตเผื่อจากจุดตัวอย่าง และเพิ่ม sagitta ของส่วนโค้งที่แบ่ง12ช่วง ส่วนโค้งต่อเนื่อง/เกลียว/shape link และปลายสั้นหรือเส้นปิดยังใช้การเผื่อแบบเดิม การหาคำตอบระยะระหว่างเซตนูนที่ยังไม่ลู่เข้าจะไม่ผ่อนผลตรวจเดิม

ตัวตรวจผิวที่มีขอบใช้ support points และ simplex ระหว่างชิ้นส่วนเหล็กกับสามเหลี่ยมของผิวคอนกรีต แนวทางระยะระหว่างเซตนูนอ้างอิง [Gilbert, Johnson and Keerthi, IEEE 1988](https://web.eecs.umich.edu/~grizzle/GilbertFest/Gilbert%2858%29.pdf) การทดสอบซอฟต์แวร์ใช้สูตรระยะของหน้าตัด/ขอบผิวที่คำนวณแยกและการหมุน rigid body เอกสารนี้ไม่ได้ทำให้ตัวตรวจได้รับการรับรองวิศวกรรม

ไม่เปลี่ยนสูตรคอนกรีต แบบหล่อ ยาวตัด BS/แนวศูนย์กลาง น้ำหนัก หรือจำนวน Legacy/Frozenเดิมยังใช้ตัวตรวจเดิมและ IDเดิม รุ่นใหม่ต้องมี IDที่ตรงนโยบายก่อนอ่านเป็น Frozen ที่รองรับ การถอดนโยบายจะถูกปฏิเสธหากสมาชิกผ่านเฉพาะวิธีใหม่ ต้องแก้ข้อมูลให้ผ่านวิธีเดิมก่อน

## ร่าง C1-100 ที่ตรวจในรอบนี้

ข้อมูลอ่านจากแบบต้นฉบับ: สมาชิก700×700×6600mm, quantity1, ระยะ50mmที่รูปหน้าตัด, ปริมาตร3.234m³, Mark309 Ø25/SD40/24แท่ง/ยาวตัด7300mm และรูปที่ระบุ6400/203/700กับ7° แถวMark4/5และค่าต้นทางทั้งหมดเก็บไว้แยกกัน

ข้อมูลที่กรอกเป็น **สมมติฐานรอตรวจ**: ฐานมิติแบบผิวนอกแต่ละช่วง, rด้านใน87เป็นอ้างอิง BSชนิดTที่ยังไม่เทียบ SD40, ผิวนอก25, หมุนแม่แบบZ=-45°, พิกัดศูนย์กลาง74.5..625.5จาก50+12+25/2และระยะเท่ากัน7ต่อด้าน, จุดเริ่มZ50, สลับoffset700ตามลำดับ, มุมแต่ละด้าน/มุมกรอบ และขอบเขตคอนกรีตบน700×700×1600สำหรับตรวจการวางเท่านั้น การตีความ50mmเป็น datumปลายและการจัดกลุ่มระดับต้องตรวจต้นฉบับอีกครั้ง

ร่างนี้ได้คอนกรีตของสมาชิก3.234m³, แบบหล่อ18.48m², เหล็กหลัก24แท่งและยาวตัด7300 โดยไม่รวมคอนกรีตอ้างอิงใน BOQ ยังไม่สร้างMark4/5 ไม่เทียบเกรด BS ไม่ยืนยันมิติ/ตำแหน่ง และไม่มีน้ำหนักเหล็กครบตามขอบเขต การตรงของจำนวน/ยาวตัดไม่รับรองรูปหรือการติดตั้ง
