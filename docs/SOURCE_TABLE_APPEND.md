# รับตาราง BBS จากหลายหน้า — v0.91

เปิดสมาชิก → ตรวจเทียบ BBS จากแบบ → อ่านตารางจาก PDF แล้วตรวจยืนยัน รับหน้าแรกและบันทึกก่อน จากนั้นเลือก PDF ต้นฉบับเดิม อ่านหน้าใหม่ แล้วเลือก **เพิ่มเป็นหน้าใหม่ในตารางเดิม** ระบุฐานจำนวนเดียวกับหน้าเดิมและบันทึกที่มา/ขอบเขต ตรวจภาพและทุกตัวเลข ยืนยันหน่วย mm/kg การตรวจต้นฉบับ และการล้างการจับคู่ BBS ก่อนกดเพิ่มและบันทึกสมาชิก

หน้าจอแสดงจำนวนรายการก่อน–หลัง หน้าเดิม/หน้าเพิ่ม และแจ้งว่าการจับคู่ BBS ทั้งชุดถูกล้าง ต้องทบทวนและจับคู่ใหม่ ตารางนี้เป็นข้อมูลอ้างอิง ไม่เพิ่มเหล็กเข้า BOQ หรือรายการตัด และไม่เปลี่ยนเป็นอนุมัติวิศวกรรม มิติ/จำนวนสมาชิกที่ยังเป็นค่าเริ่มต้นต้องคง Provisional จนผู้ใช้ตรวจข้อมูลจริง

รับเพิ่มได้เฉพาะไฟล์ attachment และ SHA256 เดียวกัน ฐานจำนวนเดียวกัน หน้าไม่ซ้ำ และ Mark ไม่ซ้ำแบบไม่แยกตัวพิมพ์ใหญ่–เล็ก สูงสุด300รายการ/20หน้า ตารางที่อ่านไม่ครบถูกปฏิเสธ ไม่รวมจำนวน Mark ซ้ำหรือไฟล์อิสระให้อัตโนมัติ ผู้ใช้ต้องตรวจว่าหน้าใหม่อยู่ในสมาชิก/ขอบเขตเดียวกันจริง; การอ่านได้ไม่ได้พิสูจน์ขอบเขตนั้น

ข้อมูลหลายหน้าใช้ sourceSchedule v3: sourcePage ของแถวเป็นหน้าตาราง; shapeReference.page เป็นหน้ารูปดัดซึ่งอาจอยู่ในอีกหน้ารายละเอียดที่ผู้ใช้เลือกเอง pageTables เก็บ Total ที่พิมพ์และบันทึกแต่ละหน้า ไม่มี Total เดี่ยวที่อ้างว่าเป็นยอดพิมพ์รวมทั้งชุด เก็บความต่างของผลรวมแถวกับ Total แต่ละหน้าให้ตรวจ ไม่มีเกณฑ์ tolerance ที่ระบบรับรอง

Excel เพิ่ม Source Page Register และแสดงหน้าของทุกแถวใน Source BBS Check/Notes/Unit Weight/Print; PDF มีทะเบียนหน้าต้นทางและหน้ารูปดัด ใช้กรอบชื่อแบบเดิมพร้อมสถานะอ้างอิง Frozen และ Backup/Restore เก็บข้อมูลดังกล่าว โดย Restore เปลี่ยน attachment ID ตามโครงการปลายทางแต่รักษา SHA256/แถว/กรอบรูป ไม่มีการอนุมัติหรือถ่ายสิทธิ์จากโครงการเก่า

เวอร์ชัน1/2เดิมอ่านได้ตามเดิม รุ่นเก่าที่ไม่รองรับv3อาจปฏิเสธข้อมูลใหม่ จึงต้องปิดแท็บรุ่นเก่าก่อนทำงานกับตารางหลายหน้า ทะเบียนหน้าที่รับแล้วและ Total เป็นข้อมูลจากการรับต้นฉบับในรุ่นนี้ ยังไม่มีหน้าจอแก้ทะเบียน/ลบทั้งหน้าแยกต่างหาก; แก้ค่ารายการได้ แต่ห้ามลบรายการสุดท้ายของหน้า เปลี่ยนไฟล์จะยืนยันล้างตารางหลายหน้าทั้งชุด ต้องอ่านและตรวจใหม่

ตัวอย่าง B104 หน้า2มี40รายการ Total2908.61kg ผลรวมแถว2908.59kg ส่วนหน้า19มี15รายการ Total891.57kg ชุด55รายการใช้ทดสอบซอฟต์แวร์เท่านั้น สมาชิก QA ยังเป็นมิติชั่วคราวและไม่มี BBS ที่สร้างจากแบบจริง ไม่ใช่ชุดส่งก่อสร้าง ไม่มีการสร้าง BS shape/SD40 mapping/ตำแหน่งเหล็กจากรูปโดยอัตโนมัติ
