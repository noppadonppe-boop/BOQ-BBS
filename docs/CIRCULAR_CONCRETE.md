# หน้าตัดวงกลม — v0.87

ใช้กับทรงกระบอกหน้าตัดคงที่ตามแกน X/Y/Z และช่องเปิดวงกลมร่วมศูนย์ตลอดความยาว เหมาะสำหรับกรอกมิติจากแบบที่ตรวจแล้ว ยังไม่รองรับทรงกรวย รูเยื้องศูนย์ หรือหลายทรงกระบอกรวมกัน

1. เลือกวิธีรูปทรงคอนกรีต **รุ่น 4** ใน General Spec แล้วบันทึก การเปลี่ยน Spec ต้องดำเนินงานปรับข้อมูลให้ครบก่อนทำงานต่อ รุ่นแบบ Frozen เดิมคงข้อมูลและวิธีคำนวณเดิม
2. เปิดสมาชิก กด **หน้าตัดวงกลม** ระบุแกน ตำแหน่งเริ่ม ความยาว เส้นผ่านศูนย์กลางภายนอก และช่องเปิด (0 = ตัน) พร้อมที่มาจากแบบ
3. เลือกผิวแบบหล่อภายนอก ภายใน และหน้าต้น/ปลายตามสภาพจริง ผิววงกลมเลือกทั้งรอบ เครื่องมือนี้ยังไม่แบ่งผิวรอบวงเป็นช่วง
4. ตรวจปริมาณต่อชิ้นก่อนใช้รูปทรง ตรวจรายการหัก งานขุด Lean และข้อมูลเหล็กที่คงอยู่จากสมาชิกเดิม แล้วบันทึกสมาชิก
5. ตรวจตำแหน่งและยืนยันเหล็กใหม่ การเปลี่ยนรูปทรงล้างการยืนยันเดิม และแทนที่กล่อง ช่องเปิด Pedestal และชุดช่วงคานเดิมทั้งหมด

ปริมาณคอนกรีตต่อชิ้น = π(R²−r²)L / 10⁹ เมื่อมิติเป็น mm ส่วนแบบหล่อใช้ 2πRL สำหรับผิวภายนอกที่เลือก, 2πrL สำหรับผิวช่องเปิดที่เลือก และ π(R²−r²) ต่อหน้าแบบหล่อหัว/ท้าย จากนั้นหาร 10⁶ เป็น m² รายการหักและจำนวนองค์ประกอบใช้วิธีเดิม ไม่คูณซ้ำ

Excel เพิ่มแผ่น Circular Geometry พร้อมสูตร π และข้อมูลรัศมี/ผิวแบบหล่อ เป็นตารางตรวจข้อมูลที่จับไว้ การแก้ตารางนี้ไม่แก้ BOQ/BBS ในโครงการ รูป 3D และวงกลมในแบบใช้แนวแสดงผล 64 จุดแบบ NTS; ปริมาณ การอยู่ภายในวงกลม และความกว้างรูปตัดด้านข้างใช้รัศมีจริง

ระยะหุ้มด้านวงกลมตรวจด้วยขอบเขตผิวเหล็กแบบอนุรักษ์นิยม จึงอาจปฏิเสธปลายตัดตามแนวรัศมีที่ผู้รับผิดชอบเห็นว่าใช้ได้ ไม่มีการชดเชยปลายตัดด้านรัศมีอัตโนมัติ การตรวจนี้ไม่รับรองระยะฝัง ทาบ ระยะเรียง BS/ACI หรือความพร้อมก่อสร้าง

เหล็กที่ขนานแนวมองแสดงเป็นจุดตามเส้นผ่านศูนย์กลาง หน้าจอและ PDF ใช้ตำแหน่งของแต่ละแท่งจริง จำนวนในตารางยังคงเดิม การปิดหน้าต่างแก้ไขให้ใช้ปุ่ม **ปิด**; Escape ยังไม่รองรับในหน้าต่างร่วม
