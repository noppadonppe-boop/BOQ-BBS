# ตรวจ Backup ก่อนกู้คืน — v0.38

หน้าตั้งค่าโครงการมี **ตรวจ Backup ZIP** สำหรับเปิดดูชุดสำรองก่อนเริ่มกู้คืน ระบบตรวจโครงสร้างสมาชิก สเป็ค รหัสซ้ำ ความสัมพันธ์ของไฟล์ ดัชนีประวัติ ขนาดและ SHA256 ของไฟล์จริง รวมถึงเปิดอ่าน PDF/ภาพเพื่อตรวจจำนวนหน้า การเลือกไฟล์ขั้นนี้ไม่อัปโหลดไฟล์หรือสร้างงาน Restore

เมื่อผ่าน จะเห็นโครงการต้นทาง วันเวลาชุดสำรอง รุ่นกฎคำนวณ จำนวนสมาชิก/องค์ประกอบ/Mark/ผลวัดรายชิ้น รายการแบบ ประวัติ Zone และชั้น พร้อมโครงการปลายทาง หากไม่ต้องการดำเนินต่อ ให้กด **ยกเลิกการเลือก Backup**

ผู้ดูแลโครงการเท่านั้นที่กด **เริ่มกู้คืนลงโครงการนี้** ได้ ปลายทางต้องไม่มีสมาชิก แบบต้นทาง สต็อก ธุรกรรมสต็อก แผนตัด หรือประวัตินำเข้า และไม่มีงานที่ล็อกการแก้ไข ระบบตรวจปลายทางก่อนอัปโหลดและตรวจซ้ำตอนเริ่มงาน หากรุ่นข้อมูลหรือประวัติเปลี่ยนหลังตรวจจะปฏิเสธการเริ่มงาน

## สิ่งที่นำคืนและสิ่งที่ต้องตรวจ

- คงรหัส ชื่อ ตำแหน่ง เจ้าของ ข้อมูลทั่วไป และสิทธิ์ผู้ใช้ของโครงการปลายทาง ไม่คัดลอก ACL จาก Backup
- นำคืนสเป็คและกรอบชื่อแบบ แต่ล้างการอนุมัติสเป็คและหลักฐานอนุมัติ
- สมาชิกกลับสถานะ Draft และล้างการยืนยันมิติ BS/ตำแหน่งเหล็ก ผลวัดรายชิ้นเดิมคงอยู่เป็นหลักฐาน
- แบบต้นทางได้รหัสและตำแหน่งไฟล์ใหม่ในโครงการปลายทาง ความสัมพันธ์ของแบบปรับตามรหัสใหม่ และล้างผลตรวจอนุมัติแบบต้นทาง
- สต็อกที่จองกลับเป็น 0 แผนตัดที่ยังไม่ใช้กลับ Cancelled แผนที่ Consumed คงสถานะเดิมไว้เป็นข้อมูลอ้างอิง
- Frozen และประวัติเก็บเป็น Imported History พร้อมข้อมูลและไฟล์ต้นฉบับ ไม่แปลงประวัติเป็นฉบับอนุมัติของโครงการใหม่

ตรวจสมาชิก แบบ แหล่งอ้างอิง สเป็ค และผลคำนวณก่อนยืนยันข้อมูลหรือออกฉบับใหม่ SHA256 ยืนยันว่าเนื้อหาตรงกับดัชนีในแพ็กเกจ ไม่ยืนยันผู้อนุมัติหรือความถูกต้องทางวิศวกรรม

## ขอบเขตที่รองรับ

รองรับ Snapshot schema 1/2 โดยไม่แก้ไขแพ็กเกจหรือย้ายรุ่นกฎคำนวณอัตโนมัติ ใช้กฎและรูปทรงที่แอปรองรับในการตรวจข้อมูลสมาชิก การเปิด Frozen เดิมยังใช้หลักฐาน/กฎของฉบับนั้น ไม่มีการปรับความยาวหรือมิติเหล็กจากการ Restore

ขีดจำกัดก่อนโอนไฟล์: สมาชิกไม่เกิน 5,000 รายการ ประวัติไม่เกิน 10,000 รายการ ข้อมูลนำคืนรวมไม่เกิน 20,000 เอกสาร manifest/history ไม่เกิน 20MiB ต่อส่วน เอกสารเข้ารหัสต้องต่ำกว่า 900,000 ไบต์ ดัชนีงานต่ำกว่า 700,000 ไบต์ และ manifest ที่จัดทำเพื่อกู้คืนไม่เกิน 20MiB ขนาดแพ็กเกจและไฟล์จริงยังใช้หน่วยความจำของเบราว์เซอร์ ต้องทดสอบกับขนาดโครงการจริงก่อนกำหนดขีดจำกัดใช้งาน

ไฟล์ที่เสียหรือข้อมูลไม่ถูกต้องถูกปฏิเสธก่อนอัปโหลด การเริ่มกู้คืนจริงยังเป็นการโอนหลายไฟล์และเขียนหลายชุด หากเครือข่ายหรือสิทธิ์เปลี่ยนระหว่างทาง อาจมีไฟล์พักค้างใน Storage การย้อนกลับ Storage ทั้งชุดแบบ atomic และการล้างไฟล์พักอัตโนมัติยังไม่ได้เพิ่ม รุ่นนี้คงการทำต่อ/ยกเลิกงาน Restore เดิม

## หลักฐานการพัฒนา

[รายงาน v0.38](../output/restore-preflight-verification/DEVELOPMENT_REPORT.html) แยกการตรวจในเครื่องออกจากการตรวจรับ Production: 532 unit tests และ 34 เส้นทาง SDK/อ่านอย่างเดียว/หน้าจอพัฒนา/หน้าจอ compiled กู้คืนสมาชิก 6 รายการ องค์ประกอบ 18 ชุด ผลวัด 35 รายการ เก็บไฟล์ Excel/PDF เดิม 7 ไฟล์ตรงกันทุกไบต์ และทดสอบแบบ GULF ต้นฉบับอีกโครงการ

GULF pilot เป็นข้อมูลมิติอ้างอิงเท่านั้น ยังไม่ได้ถอดเหล็ก Mark หรือรับรอง cover: จำนวน Mark เป็น 0 หมายถึงยังไม่กรอก ไม่ใช่ไม่มีเหล็กในแบบ กฎคำนวณยังเป็น geometry-2.2+bs8666-2000-v7 และมาตรฐานขั้นต่ำจาก BS8666:2000 พร้อม amendments ที่ผู้ใช้ให้ไว้ ไม่ใช่การรับรอง BS/ACI เต็มฉบับ

กฎ Firestore/Storage, .env, Auth และส่วนเชื่อมต่อเดิมคงไว้ตามการจัดการของผู้ใช้ ไม่มี Cloud Functions ไม่มีการ deploy Rules หรือ Hosting ผลทดสอบเฉพาะส่วนนี้ยังไม่ใช่การตรวจรับระบบเต็มหรืออนุญาตออก BBS ก่อสร้าง
