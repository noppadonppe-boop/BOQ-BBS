# Source per-piece weights — v0.83 local development

The source BBS comparison accepts optional `Kg/p` as the literal printed weight per bar piece. Zero and missing input are distinct. Native-table intake retains this column and rejects a declared but unreadable cell rather than discarding it. Old tables without this column remain supported.

The app shows calculated BBS weight per piece, its difference from the printed input, the source `Kg/p × count`, and the printed row weight minus that product. Per-piece values are never multiplied by member occurrence quantity. These diagnostics do not change geometry, BOQ, cutting demand, the Mark/count/cut comparison gate, or engineering approval. No rounding tolerance or steel-grade equivalence is inferred.

An optional `Source Unit Weight` worksheet links calculated mass to the existing BBS cut-length/unit-mass cells; missing values remain blank. Supplemental PDF pages have been added to the export code. Actual signed app A3/PDF and Excel exports, SHA256 readback, per-piece/row-product recalculation and visual review now pass for the genuine source-only C1 case. A1 and bounded300-row pagination with owner frames were verified in v0.84; see SOURCE_OWNER_PAGINATION.md for exact scope and visual-review limits. Native Excel print behavior and engineering/owner acceptance remain open.

Current evidence: 1,441 unit tests; TypeScript; retained native text from seven supplied PDF tables/59 rows matched to current original-file hashes; standalone React review at desktop/mobile sizes. The original full application fixture failed because it did not provide Auth context; its evidence is retained. The replacement standalone review fixture passes and is explicitly not a persistence, upload, full-editor, compiled-app or export test. The earlier listener enumeration was insufficient: subsequent direct TCP and signed SDK checks proved the existing isolated emulators were live. They were reused without restarting services or changing Rules. Actual original-PDF upload/native intake, full-editor save/reload of zero/missing/printed values, Frozen isolation, Backup/Restore of source bytes and inactive approval, and a persisted synthetic mapped-bar quantity-scope test pass. Immediate editing after save also passes using keyboard events; earlier Playwright fill-empty attempts omitted the input event and are retained as test failures, not a proven product defect.
