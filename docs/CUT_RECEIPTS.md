# บันทึกตัดบางเส้นและเศษวัดจริง

รุ่น0.75เพิ่ม [การจัดชุดจากยอดชิ้นงานที่เหลือ](CUT_BATCHES.md) รวมถึงภายใน occurrence เดียวหลังยกเลิกแผนบางส่วน ข้อจำกัดการจัดชุดในรายงานรุ่น0.74ด้านล่างเป็นสถานะของรุ่นนั้น

รุ่น 0.74 เพิ่มใบตัดสำหรับเส้นวัตถุดิบที่ทำครบแพตเทิร์นแล้ว โดยไม่ต้องรอทั้งแผนเสร็จ เศษกลับสต็อกใช้ความยาวที่วัดจริง และแยกความสูญเสียเพิ่มเติมจากรอยตัด/เศษทิ้ง งานนี้ไม่เปลี่ยน Rules, Auth, configuration หรือ deploy

## บันทึกทีละชุด

เปิดแผน Issued ที่ Reserved แล้วกด **บันทึกตัดตามฉบับ Issued** เลือกเส้นที่ตัดครบตามแพตเทิร์น ครั้งละไม่เกิน160เส้น ระบุเลขใบตัดหรือบันทึก ตำแหน่งเก็บเศษจริง และความยาวเศษแต่ละเส้น ตัวเลือกข้ามหน้าคงอยู่จนบันทึก

เศษวัดจริงต้องเป็น0ขึ้นไป ไม่เกินเศษตามแผน และละเอียดไม่เกิน0.001mm เมื่อเศษสั้นลง ต้องระบุเหตุผลความสูญเสียเพิ่ม เช่นตัดหัวหรือเศษเสีย ระบบไม่เปลี่ยนความยาวชิ้นงาน BBS หากเศษยาวกว่าแผน ต้องตรวจความยาววัตถุดิบ/รอยตัดและจัดแผนที่ถูกต้องก่อนบันทึก ไม่รับการเพิ่มความยาวสต็อกด้วยข้อมูลที่ขัดกับยอดความยาว

ยอดวัตถุดิบของเส้นที่เลือกเท่ากับชิ้นงานตาม BBS + รอยตัด + เศษเก็บจริง + เศษทิ้งจริง + ความสูญเสียเพิ่ม เศษที่ยาวถึงเกณฑ์เก็บสร้างเป็นล็อต Offcut ที่ตำแหน่งระบุ เศษสั้นกว่าเกณฑ์เป็น scrap ไม่มีล็อตพร้อมใช้

แต่ละใบตัดลด quantity/reserved เฉพาะเส้นที่เลือก เส้นที่เหลือยังจองอยู่และแผนคง Reserved เมื่อทุกเส้นบันทึกครบจึงเปลี่ยนเป็น Consumed รายการที่ตัดแล้วเลือกซ้ำไม่ได้ Retry ด้วยรหัสคำขอเดิมไม่ตัดซ้ำ คำสั่งตัดเต็มแผนเดิมใช้กับแผนที่มีใบตัดบางเส้นแล้วไม่ได้

## ยกเลิกส่วนที่เหลือและตรวจประวัติ

ยกเลิกได้เฉพาะแผน Reserved ระบบคืนยอดจองของเส้นที่ยังไม่ตัด ไม่คืนเส้นที่ใช้แล้วเป็นสต็อกพร้อมใช้ และยังนับยอดชิ้นงานตามตำแหน่งที่ผลิตแล้วเพื่อกันการผลิตซ้ำในฉบับเดียวกัน การยกเลิกทำได้แม้ฉบับเก่าถูกแทนที่แล้ว

ก่อนบันทึกครั้งถัดไป ระบบเทียบ executionState กับ stockLedger หากใบตัดหาย ข้อมูลเส้นถูกลบ เศษจริง/outputs/ยอดก่อน–หลังไม่ตรง จะปฏิเสธการทำต่อ ทะเบียนสต็อกแสดงปัญหาแทนการรับรองยอด ส่วนประวัติในแผนแสดงใบตัด เส้นที่ทำจริง เศษเก็บ/ทิ้ง และความสูญเสียเพิ่ม

Excel แผนตัดเก็บแพตเทิร์นและยอดแผนเดิมไว้ และเพิ่ม **Actual Cut Receipts** สำหรับผลวัดจริง การส่งออกส่วนนี้ต้องมีประวัติครบและ checksum แพตเทิร์นตรง ไม่ใช้ผลวัดจริงเขียนทับฐาน BBS หรือปริมาณ BOQ ไฟล์แผนไม่ให้การอนุมัติวิศวกรรมใหม่

## ข้อมูลและเงื่อนไขสำหรับเจ้าของ Rules หรือ API

| ข้อมูล | เงื่อนไข |
| --- | --- |
| `consumeCutting.receipt` | version1, confirmedPatterns=true, note, offcutLocation และ rows ที่มี patternIndex/actualRemainder/lossNote; เลือกเส้นที่ยังไม่ทำและไม่ซ้ำ |
| `cutPlans.executionState` | version1, patternDigest, completed ของแต่ละเส้นและ receiptIds แบบเพิ่มประวัติ ไม่ลบเส้นที่ผลิตไปแล้ว ไม่แก้ patterns/allocations/BBS |
| `stockLedger CutReceipt` | recordVersion3, rows, requirements, movements, outputs, totals, issuedReference, execution, createdBy/At สอดคล้องกันและ immutable |
| ยกเลิกบางส่วน | Cancelled รุ่น3มี remainingPatterns และ movements คืน reserved เฉพาะส่วนที่ยังไม่ตัด quantity ไม่เพิ่ม เส้นที่ผลิตแล้วและยอดตามตำแหน่งคงอยู่ |
| ข้อจำกัด transaction | UID/บทบาทแยกโครงการ แผน/stockEpoch/ฉบับยังตรงก่อน commit ตัดยอดและสร้างเศษพร้อมใบตัดครั้งเดียว รวมกลุ่มเศษและสต็อกไม่เกิน160ต่อคำขอ |

patternDigest เป็น SHA256 ของ patterns, kerf, minOffcut และ allocations ต้องบังคับข้อมูลและยอดชิ้นงานฝั่งเซิร์ฟเวอร์ รวมถึงการห้ามข้ามขั้นผ่าน SDK/REST การตรวจ client ไม่แทนสิทธิ์/นโยบายดังกล่าว Rules ปัจจุบันยังไม่เปิด CutReceipt และ executionState ผู้ใช้เป็นผู้กำหนดและ deploy เอง ไม่มีการเปลี่ยน Rules ในงานนี้

## ผลตรวจและงานค้าง

การรับ/จอง/ยกเลิก การปฏิเสธตัดโดย Rules เดิม สิทธิ์ Viewer/โครงการอื่น การปฏิเสธ Frozen และคำสั่ง receipt ที่ไม่มี Issued ผ่าน Firebase จำลองจริง Web Worker และหน้าจอ build ผ่านการตรวจ ส่วนฟอร์มใบตัดผ่าน component QA ที่ไม่มีการเขียนฐานข้อมูล

positive partial receipt, cancel remainder, เศษวัดจริง/replay/stock epoch race และ retained manufacturing allocation ตรวจด้วย transaction/domain doubles; Restore และ XLSX ของข้อมูลใบตัดใหม่ทดสอบ retention/serialization เท่านั้น ไม่ได้ยืนยันการพิมพ์หรือการบันทึก Issued จริง ต้องทดสอบกับนโยบายเจ้าของและหลักฐานวิศวกรรมที่รับรองก่อนใช้ตัดจริง

ยังไม่รองรับการตัดไม่ครบแพตเทิร์นภายในเส้นเดียว เปลี่ยนความยาวชิ้นงาน BBS หรือแบ่งการจัดแผนตามจำนวนชิ้นที่เหลือใน occurrence เดียวโดยอัตโนมัติ หลังยกเลิกแผนที่ผลิตไปบางส่วน ยังต้องเพิ่มเครื่องมือจัดชุดเฉพาะยอดชิ้นงานที่เหลือ งานนี้ไม่ปิดข้อกำหนดเดิมทั้ง12ข้อ และยังรอ BS/ACI/วัสดุ/ปิดปลาย/GULF/เจ้าของงานและ Production
