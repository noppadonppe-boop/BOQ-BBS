# พิมพ์ BOQ และ BBS จาก Excel — v0.56

แก้ปัญหาที่ Microsoft Excel แยกคอลัมน์สถานะข้อมูลเหล็กของ BOQ ไปอีกหน้า โดยกำหนด BOQ Print ให้พิมพ์กว้างหนึ่งหน้า A3 แนวนอน และแบ่งหน้าตามแนวตั้งได้ตามจำนวนรายการ ปริมาณและสูตรเดิมไม่เปลี่ยน

## วิธีใช้งาน

1. เลือกโครงการ ขอบเขตสมาชิก/ประเภท/Zone/ชั้น และ Working หรือ revision ที่ต้องการในแอป แล้วส่งออก Excel
2. เปิดไฟล์ใน Microsoft Excel ตรวจชื่อโครงการ ขอบเขต revision และสถานะ Draft/Frozen ก่อนพิมพ์
3. เลือกแท็บสำหรับส่งงาน: BOQ Print, Rebar Summary และ BBS Print หากไฟล์มีมุมมองที่บันทึกไว้ ให้เลือก Drawing Views เพิ่มเพื่อแนบข้อมูลระนาบและตำแหน่งรูปตัด
4. ใช้ Print Active Sheets ตรวจ A3 แนวนอนและพื้นที่พิมพ์เดิม BOQ Print ใช้ความกว้างหนึ่งหน้า ความสูงอัตโนมัติ
5. ตรวจ Print Preview ให้สถานะข้อมูลเหล็กอยู่หน้าร่วมกับปริมาณ ตรวจข้อความไทย รูปเหล็ก Mark และยอดรวมทุกหน้า
6. เก็บ XLSX ต้นฉบับจากแอปไว้ หากต้องการ PDF ของตาราง Excel ให้พิมพ์/ส่งออกแท็บที่เลือกเป็น PDF แล้วตรวจจำนวนหน้าอีกครั้ง

แท็บข้อมูลและสูตรอื่นมีไว้ตรวจรายละเอียด การเลือกพิมพ์ทั้ง workbook จะรวมแท็บเหล่านั้นด้วย PDF ที่พิมพ์จาก Excel เป็นตารางที่เลือก ส่วน BBS drawing PDF จากแอปมีการจัดรูปแปลน รูปตัดและกรอบแบบแยกต่างหาก

## ขอบเขตที่ตรวจจริง

ตรวจด้วย Microsoft Excel16.0 build16130 เปิด XLSX ต้นฉบับแบบอ่านอย่างเดียว คำนวณใหม่ และส่งออกสี่แท็บที่เลือกโดยรักษาพื้นที่พิมพ์ ได้ A3 แนวนอนสี่หน้าต่อไฟล์ ทั้ง Working และ Frozen รวมแปดหน้าที่ตรวจภาพแล้ว

ข้อมูลเป็นกรณีทดสอบเสา SECTION-C1: คอนกรีต3.234m³ แบบหล่อ18.48m² และเหล็กที่กรอก40.563239033502256kg จำนวนห้าชิ้น ตำแหน่ง B-B ของ Frozen เป็นZ1000mm ส่วน Working เป็นZ1200mm ทั้งสองไฟล์มีรูปเหล็กห้ารูป และ Code00 ยังคงเป็นข้อความ `00` ข้อมูลเหล็กเป็นข้อมูลสังเคราะห์ ไม่ใช่การถอดเหล็กจากแบบ GULF

เครื่องนี้ใช้ Arial/Tahoma ทดแทน Sarabun ที่ระบุในไฟล์ ข้อความไทยในแปดหน้าที่ตรวจอ่านได้ การใช้เครื่องหรือเครื่องพิมพ์อื่นอาจเปลี่ยนการจัดหน้า จึงต้องตรวจ Preview ของชุดที่จะส่งจริง โดยเฉพาะข้อความยาวและข้อมูลหลายหน้า

ยังไม่ได้ตรวจเครื่องพิมพ์จริง ชุดข้อมูลขนาดใหญ่ หรือแท็บอื่นด้วย Excel ในรอบนี้ การพิมพ์ผ่านไม่ใช่การรับรองกฎวิศวกรรม ปริมาณโครงการจริง หรืออนุมัติออกแบบก่อสร้าง Rules และการ deploy ยังคงเป็นหน้าที่ของผู้ใช้
