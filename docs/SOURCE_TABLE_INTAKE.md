# Native PDF BBS table intake — v0.65

In a member, open **ตรวจเทียบ BBS จากแบบ → อ่านตารางจาก PDF แล้วตรวจยืนยัน**. Choose an attached, current PDF and the page that contains its BBS table. The file must have verified original bytes, SHA256 and page count. Read the page, inspect the original table and proposed row figures, choose the quantity basis, enter a source/scope note and explicitly confirm mm/kg and the values. Accepting changes the local member; save the member to persist it.

This reads positioned native text under a single `REBAR BENDING SCHEDULE` title with separate Pos/Mark, Diameter, Number/Q'ty, Grade, Length, Weight and Bending shape columns. It does not OCR scanned drawings, merge multiple tables/pages, reconstruct bars, infer a BS material type, apply the drawing's member quantity, map matching Mark names or approve a source. Unreadable, ambiguous, invalid or duplicated rows prevent acceptance; partially read tables cannot be accepted by dropping failed rows.

Page rotation flags can be compensated by the PDF's text matrices. The parser uses the visible text baseline and viewport coordinates. A genuinely sideways table requires manual entry. Small-font dimensions in the shape column are not numeric weight cells. The supplied31 pages contain7 such tables:4 column tables/3 rows each, B101/B102 page1/16 rows each, B104 page19/15 rows; the24 other pages are not tables.

Visual inspection confirms that the beam link is **Mark28**, not281: the old merged string `2812…` combines Pos28 with diameter12. No app geometry is built from this correction. Original C1 source row sum862.49 versus stated total862.50 remains visible and unresolved. Imported SD40 remains a literal reference grade; no SD40→BS type mapping is inferred.

The proposed shape rectangles are references in the visible original page, not bending geometry or a fabrication path. They can include table borders or nearby source labels. Inspect each crop and adjust it using **เลือกรูปดัดต้นทาง** when needed. Source tables are version2 data already supported by copy/Frozen/BackupRestore. Acceptance assigns fresh row IDs, clears all BBS mappings and returns the member to Draft while resetting bar confirmations. Replacing an existing table requires deliberate confirmation.

Existing BBS/BOQ/cutting demands remain separate. Blank BBS mass/count/cut values stay pending. Known source weight without a mapped BBS now says **น้ำหนัก BBS ยังไม่พร้อม**, including its source weight; it is no longer mislabeled as missing source input. An unentered complete-steel quantity is blank, not an accepted zero.

For A3 printing, use **Source BBS Print** and **Source Shapes Print**. They fit one page wide, allow vertical continuation, retain original image aspect ratios and reuse the original embedded pictures. Full data, formulas, source hashes, notes and diagnostics remain in Source BBS Check/Notes/Shape References. These supplemental reference sheets are not construction BBS approval.
