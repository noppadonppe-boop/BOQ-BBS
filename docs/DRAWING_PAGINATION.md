# ตาราง BBS ที่ต่อหน้า — v0.78

รูปแบบ BBS แปลน/รูปตัด/ตารางเหล็ก (`schedule-v1`) รองรับแถวอ้างอิงยาวและตารางที่ข้ามหน้าแล้ว ทุกหน้าที่ตารางสร้างเพิ่มมีหัวแบบ แปลน/รูปตัดของกลุ่มเดิม กรอบชื่อแบบ และเลขแผ่นตามจำนวนหน้าจริง การส่งออกไม่ใช้จำนวนกลุ่ม Mark แทนจำนวนหน้าที่พิมพ์จริง

แถวต่อเนื่องอ้างรหัสเหล็กเดิม ไม่ใช้ลำดับแถวใหม่ของตารางซึ่งอาจเป็นค่าติดลบเมื่อแถวแบ่งหน้า หากแถวเดียวต้องแบ่ง จะระบุ Markพร้อม `(cont.)` และต่อข้อความที่เหลือ ค่าจำนวนและน้ำหนักของแถวนั้นไม่กลายเป็นเหล็กเพิ่ม หัวหน้าระบุ TABLE CONTINUED เมื่อตารางกลุ่มเดียวข้ามหน้า

แปลน/รูปตัดซ้ำบนหน้าต่อเนื่องเพื่อใช้หาตำแหน่งของกลุ่ม Markนั้น เมื่อแนวตัดไม่ผ่านเหล็ก จะแสดงชื่อ Markในรายการ Not intersecting this cut และไม่สร้างจุดชี้ปลอม เลขแผ่นกรอบโครงการนับทุกหน้าของสมาชิก รวมภาคผนวกตามกลไกเดิม กรอบทั่วไปนับหน้าตารางจริงแยกสมาชิก การแสดงหลายรูปตัดซ้ำ BBSเดิม ไม่ใช่จำนวนเหล็กเพิ่มเติม

ข้อผิดพลาดก่อนแก้ถูกทำซ้ำได้กับข้อมูล8Marks/80จุดต่อMarkที่ผ่านการตรวจข้อมูลสมาชิก: เมื่อแถวตารางแบ่งหน้า การอ้าง `row.index` ทำให้หาเหล็กไม่พบและล้มด้วย reading 'paths' นอกจากนี้โค้ดเดิมลงกรอบหลังสร้างตารางจึงลงเฉพาะหน้าสุดท้าย การแก้ใช้รหัสในข้อมูลแถวดั้งเดิม ลงทะเบียนหน้าจริง และจัดเลขแผ่น/กรอบหลังรู้จำนวนหน้าทั้งหมด

หลักฐาน:1357 unit cases/90filesผ่าน;4เส้นทางจริงกับ local Firebaseและ compiled UI ผ่าน รวมบันทึก Draft/Frozen,ไฟล์ A3/A1พร้อมงาน Storageที่Complete/ตรวจSHA และพรีวิวบนคอมพิวเตอร์/มือถือ ไฟล์จริง A3มี5หน้า A1มี1หน้า เก็บ8Marksและค่าความยาวช่วงอ้างอิง632ค่าไว้ครบ ปริมาณจาก Frozenไม่เปลี่ยน

การตรวจ rendererแยกเพิ่มเติมใช้ข้อมูลควบคุม:แถวเดียวที่ต้องแบ่ง2หน้าคง79ค่าและป้ายcont.;กรอบทั่วไป2สมาชิกมี6หน้าและเลข1/5–5/5กับ1/1;สองรูปตัดพร้อมภาคผนวกมี11หน้าและกรอบเจ้าของครบ ตรวจข้อความทุกหน้ากับภาพที่render ไม่ใช้การอ่าน private WeakMapจากโมดูลทดสอบเป็นหลักฐานว่ากรอบครบ

ขอบเขตนี้แก้การนำเสนอ ไม่เปลี่ยนสูตร BS/ACI ปริมาณ หรือ Schemaข้อมูล ไม่เพิ่มการอนุมัติวิศวกรรม ข้อมูลเป็นตัวอย่างทดสอบ;รัศมี/ช่วงดัดของตัวอย่างCode99ยังไม่ผ่านขั้นต่ำและการตรวจรับผลิต ไฟล์เป็น NOT FOR CONSTRUCTION ไม่ใช่การสร้างแบบGULFจริงหรือการรับรองโดยเจ้าของงาน ยังไม่ผ่านข้อกำหนดเดิม12ข้อทั้งหมด ไม่ทดสอบพิมพ์จริง,ExcelหรือBackup/Restoreใหม่ในรอบนี้ จำกัด500หน้าตามเดิมและหยุดเมื่อจำนวนหน้าจริงเกิน
