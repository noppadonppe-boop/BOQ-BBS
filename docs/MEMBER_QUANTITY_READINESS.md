# ปริมาณรายสมาชิกและยอดรวม — v0.93

สมาชิกใหม่จากหน้าจอเริ่มด้วยมิติ/จำนวนชั่วคราว เปิด **ที่มาข้อมูลปริมาณ BOQ** ตรวจมิติ รูปทรง ผิวแบบหล่อ รายการหัก งานดิน/Lean และจำนวนองค์ประกอบเทียบแบบ ระบุเอกสาร/วิธีวัด/ขอบเขต ตรวจช่องยืนยันข้อมูลฉบับปัจจุบัน แล้วกดยืนยันและบันทึกสมาชิก นี่คือการยืนยัน input ของผู้ถอดปริมาณ แยกจากการตรวจรับวิศวกรรมและเจ้าของงาน

หน้า BOQ / วิธีคำนวณ และ KPI ของสมาชิกแสดงรอยืนยันเมื่อinputยังชั่วคราว พร้อมตัวเลขคำนวณประกอบ ยอดครบของจำนวน คอนกรีต แบบหล่อ งานดิน Lean และเหล็กที่คูณจำนวนองค์ประกอบถูกเว้นไว้ แม้กรอกBBSแล้วก็ยังต้องตรวจจำนวนองค์ประกอบให้ถูกต้อง รายการเหล็กแยกขนาดและตัวเลขrawยังดูได้ตามข้อมูลที่กรอก

ทะเบียนสมาชิกและBOQแบบMember/Category/Zone/Floor/Summaryใช้หลักเดียวกัน เฉพาะกลุ่มที่มีสมาชิกชั่วคราวถูกพักยอดครบ ตัวกรองพื้นที่ที่เลือกเฉพาะสมาชิกพร้อมยังแสดงยอดครบ การยืนยันไม่เปลี่ยนผลคำนวณraw หากแก้มิติ/จำนวนที่กระทบปริมาณหลังยืนยัน ระบบกลับProvisionalให้ตรวจใหม่ การเปลี่ยนป้ายZone/Floorอย่างเดียวไม่ย้ายพิกัดหรือเปลี่ยนสูตร

หากเริ่มBBSจากตารางรวมในPDF จำนวนต่อองค์ประกอบใช้จำนวนองค์ประกอบที่กรอกปัจจุบันเป็นตัวหาร ต้องตรวจขอบเขตและจำนวนจริงก่อนใช้ยอดรวม ระบบเตือนเมื่อจำนวน/มิติยังชั่วคราว และไม่สร้างรูปดัดจากภาพหรือจับคู่BSชนิดวัสดุให้อัตโนมัติ การกรอกรูป/ตำแหน่งยังเป็นงานแยกที่ต้องตรวจเทียบแบบ

Excel BOQ/Summary/Print/Coverageใช้ช่องว่างจริงสำหรับยอดพร้อมที่ยังขาดข้อมูล PDFใช้PENDING เหล็กrawที่แสดงประกอบระบุpreview/ชั่วคราว Quantity Basisเก็บจำนวนและปริมาณดิบตามFrozenที่เลือก ชุดตัวอย่างส่งออกใช้Frozenจำนวนรวม9;ข้อมูลทำงานหลังแก้จำนวนเป็น10 จึงต้องเลือกrevisionให้ตรงงานที่ตรวจ

Policy quantity-readiness-2.0เปลี่ยนการแสดงความพร้อมของข้อมูลที่มีquantityBasisProvisional แต่ไม่เปลี่ยนสูตร/ค่าคำนวณ/engineversion และไม่แก้bytesของFrozenหรือไฟล์ประวัติเดิม ข้อมูลLegacyที่ไม่มีquantityBasisคงพฤติกรรมเดิมพร้อมระบุว่าไม่ได้บันทึกที่มา ควรตรวจและเพิ่มที่มาของข้อมูลเก่าก่อนใช้โครงการจริง ปิดclientรุ่นเก่าที่อาจรายงานCount/steelต่างจากpolicyนี้

Backup/Restoreคงข้อมูลraw/referenceและเหล็กที่ป้อน แต่ข้อมูลที่มีbasisต้องตรวจใหม่ในปลายทาง ไม่มีการโอนอนุมัติวิศวกรรม/สิทธิ์ รายละเอียดBBSและการวางแผนตัดยังเป็นค่าDraftจากinputปัจจุบันภายใต้ขั้นตอนตรวจเดิม policyนี้ไม่รับรองการใช้Stockหรือปล่อยIssued ยังต้องตรวจรับกฎBS8666/ACI318 วัสดุ รูปดัด/ตำแหน่ง ชุดBBSเจ้าของงาน และProductionตามRules/APIของผู้ใช้
