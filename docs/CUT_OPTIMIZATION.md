# แผนตัดเหล็ก v0.29

เลือกสมาชิก ประเภท Zone หรือชั้น แล้วใส่รอยตัดและความยาวเศษเก็บขั้นต่ำ ระบบใช้จำนวนตำแหน่งที่เลือก × จำนวนเหล็กต่อองค์ประกอบเพียงครั้งเดียว ไม่ปรับความยาวตัด รูปดัด จุดต่อ หรือข้อกำหนด BS/ACI

## เป้าหมาย

ทุกโหมดจัดชิ้นงานให้ครบก่อน โดยลดจำนวนชิ้นที่ขาด แล้วลดความยาวชิ้นที่ขาด หากมีคำตอบที่ครบ จะไม่เลือกคำตอบที่ขาดชิ้นงานเพื่อให้ตัวเลขเศษดูน้อยลง

| โหมด | ลำดับหลังจัดชิ้นงาน |
| --- | --- |
| ใช้วัตถุดิบน้อยที่สุด | ความยาวสต็อกที่ใช้ → เศษทิ้ง → เหล็กใหม่ที่ใช้ → จำนวนเส้น |
| ลดเศษทิ้ง | เศษทิ้ง → ความยาวสต็อกที่ใช้ → เหล็กใหม่ที่ใช้ → จำนวนเส้น |
| ใช้เศษเดิมก่อน | เหล็กใหม่ที่ใช้ → ความยาวสต็อกที่ใช้ → เศษทิ้ง → จำนวนเส้น |

โหมดใช้เศษเดิมก่อนอาจใช้วัตถุดิบรวมมากกว่าโหมดแรก เมื่อรับเศษจากภายนอกให้เลือก “เศษเหล็กพร้อมใช้” แล้วกรอกความยาวที่พร้อมตัดจริง เศษจากประวัติ `source=Cut …` ถูกจำแนกเป็นเศษโดยอัตโนมัติ เหล็กรับเข้าเก่าที่ไม่ได้ระบุประเภทถือเป็นเหล็กใหม่ ไม่เดาประเภทจากความยาว

## การค้นหาและขอบเขต

รุ่น `cut-optimizer-2.0` แยกขนาดและเกรดแบบตรงตัว รวมช่องว่าง/ตัวพิมพ์ เปรียบเทียบ8วิธี: best fit ลดหลั่น, เปิดเส้นเดิมก่อน, เปิดเส้นยาวก่อน, เศษเดิมก่อน, best fit เรียงสั้นก่อน, สลับยาว/สั้น และสลับลำดับด้วย seedคงที่2ชุด จัดลำดับสต็อกตาม ID จึงให้คำตอบซ้ำได้ ไม่มีการสุ่มตามเวลา

กลุ่มที่มีชิ้นงานไม่เกิน14ชิ้นและสต็อกพร้อมใช้ไม่เกิน16เส้นจะค้นหาทุกการจัดที่เกี่ยวข้อง ลดทางเลือกที่สต็อกเหมือนกัน และตัดกิ่งที่ขาดชิ้นงานมากกว่าคำตอบปัจจุบัน ค้นหาไม่เกิน200,000โหนดต่อกลุ่ม และ1,000,000โหนดรวม หากค้นหาไม่ครบเพราะงบหรือขนาด ระบบแสดงว่าเป็น heuristic ไม่มีการรับรองคำตอบดีที่สุด แม้ยอดจะลงตัว เมื่อค้นหาครบทุกกลุ่ม คำตอบดีที่สุดหมายถึงเฉพาะสต็อก ความต้องการ และลำดับเป้าหมายที่ป้อน ไม่ใช่การรับรองวิศวกรรม

ใช้หน่วยจำนวนเต็ม0.001mm ไม่ปัดความยาวให้สั้นลงโดยเงียบ ค่าที่ละเอียดเกินช่วงหรือเกินความแม่นยำตัวเลขต้องแก้/แบ่งชุดก่อนคำนวณ รอยตัดคิดทุกชิ้นรวมชิ้นสุดท้าย ไม่เผื่อขอบตัดหัวท้ายเพิ่มเอง เศษเท่ากับขั้นต่ำเก็บเป็นเศษพร้อมใช้ ไม่มีการสมมติราคา ลำดับขนส่ง หรือการสูญเสียที่ไม่กรอก

รับความต้องการและสต็อกพร้อมใช้ได้ไม่เกิน100,000ชิ้น/เส้นในการคำนวณชั่วคราว ข้อเสนอที่บันทึกจำกัด1,000เส้นและ700KB เลือกพื้นที่/สมาชิกเพื่อแบ่งชุด หากเกินขอบเขตจะไม่บันทึกข้อเสนอหรือจองสต็อกบางส่วน

## คำนวณ จอง และยกเลิก

การคำนวณทำใน browser Worker หน้าจอยังตอบสนองและยกเลิกได้ ระหว่างอ่านข้อมูลหรือคำนวณ การยกเลิกไม่สร้างแผน/operation และไม่เปลี่ยนสต็อก เมื่อเข้าสู่ “กำลังบันทึก” ปุ่มยกเลิกจะปิดจนธุรกรรมเสร็จ

ระบบตรวจว่าสมาชิกและสต็อกยังเป็นรุ่นเดิมตอนบันทึก หากมีการแก้ BBS รับเหล็ก จอง หรือเปลี่ยนเศษระหว่างคำนวณ ให้คำนวณใหม่ แผนที่ขาดชิ้นงานจองไม่ได้ สองคนจองเหล็กชุดเดียวกันจะผ่านได้เฉพาะแผนที่ยังมีจำนวนพร้อมใช้พอ การยกเลิกจองคืนยอดจอง ไม่เพิ่มจำนวนเหล็กจริง

แผนเดิมไม่ถูกคำนวณทับ การดูทุกเส้นใช้หน้าละ25เส้น เปิดรายการเพื่อดู Member/Mark/ความยาว/จำนวนครบ แผนภาพรวมเหล็ก Markเดียวกันให้กระชับ หากมีเกิน16กลุ่มจะแสดงส่วนรวมของกลุ่มที่เหลือ รายการเต็มยังอยู่ด้านล่าง

การตัดจริงยังปิดใน Production ปุ่ม “บันทึกตัด (ทดสอบ)” ใช้ได้เฉพาะ demo emulator เพื่อทดสอบบัญชีสต็อกและสร้างเศษ ข้อมูลทดสอบไม่ใช่ใบสั่งตัดก่อสร้าง

## Excel และข้อมูลถาวร

Excel แผนตัดอ่านรายการที่บันทึกแล้ว มี Cutting Plan สรุปเป้าหมาย/สถานะ/ขอบเขต/วิธีเดิม, Patterns ตามเส้นสต็อก และ Cuts ตามกลุ่ม Member/Mark พร้อมสูตรเชื่อมยอด หากมีชิ้นที่ขาดจะเพิ่ม Unfilled ไม่คำนวณ BBS ใหม่หรือแก้สต็อก ชื่อโครงการในไฟล์ระบุว่าเป็นข้อมูลโครงการปัจจุบัน ส่วนรุ่น BBS/วัน/IDของข้อเสนอเป็นข้อมูลที่บันทึกไว้

ผู้ดูข้อมูลสามารถดาวน์โหลดได้ แต่คำนวณ รับเข้า จอง หรือยกเลิกไม่ได้ Backup ZIP เก็บ `optimizer`, `scope` และ `stock.kind` Restoreรักษาประวัติคำตอบแต่ยกเลิกการจองเก่าและคืนยอด reservedเป็น0 เพื่อให้ตรวจข้อมูลใหม่

ฟิลด์ `stock.kind` และ `cutPlans.optimizer/scope` เป็นข้อมูลเพิ่มเติม ผู้ใช้กำหนดและ deploy Rulesเอง ต้องตรวจความเข้ากันได้กับ Rulesที่เลือก ไม่มีการแก้ Rules, .env, Cloud Functions หรือ deploy Cloudในรอบนี้

## งานตรวจรับที่ยังค้าง

หลักฐานชุดนี้เป็นข้อมูลจำลองซอฟต์แวร์ รวม oracleอิสระ ชุดชั่วคราว100,000ชิ้น ชุดบันทึก1,000เส้น การจองพร้อมกัน เศษที่ได้จากการทดสอบ และ Excelที่ดาวน์โหลดจริง ยังไม่ตรวจเครื่องพิมพ์ Microsoft Excelจริงหรือรับรองงานโรงตัด ไม่ปิดข้อกำหนด BS/ACIครบชุด กรณีวิศวกรรมอิสระ งานนำร่อง GULF/เจ้าของงาน รูปทรงเพิ่มเติม หรือ Production
