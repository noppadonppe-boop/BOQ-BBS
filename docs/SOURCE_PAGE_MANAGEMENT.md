# จัดการหน้าตาราง BBS ต้นทาง — v0.92

เปิดสมาชิก → ตรวจเทียบ BBS จากแบบ → จัดการหน้าตารางต้นทาง เลือกแก้ข้อมูลหน้าที่ต้องการ ป้อนTotalที่พิมพ์และบันทึกที่มา ตรวจต้นฉบับ ยืนยัน แล้วบันทึกสมาชิก Totalต้องมากกว่า0หรือเว้นว่างหากยังไม่ทราบ; ค่า0ไม่แทนการไม่ทราบ การแก้ช่องใดช่องหนึ่งจะล้างคำยืนยันให้ตรวจข้อมูลปัจจุบันใหม่ ค่าที่แก้เป็นการถอด/แก้ข้อมูลอ้างอิงโดยผู้ใช้ ไม่ได้เปลี่ยนPDFต้นฉบับหรือรับรองวิศวกรรม

เลือก **ลบหน้า** เพื่อดูหน้าที่ลบ จำนวนรายการก่อน–หลัง และหน้าที่เหลือ ตรวจแล้วจึงยืนยัน หากเหลือหน้าเดียว ระบบเก็บTotal/บันทึกของหน้านั้นเป็นตารางหน้าเดียวและคงID/กรอบรูปของรายการที่เหลือ หน้ารูปดัดอาจต่างจากหน้าตารางและยังอ้างหน้าPDFที่เหลืออยู่ในไฟล์เดิมได้ ปุ่มลบหน้าสุดท้ายปิดไว้; ใช้ลบตารางทั้งชุดเมื่อต้องการเริ่มใหม่ ยกเลิกก่อนยืนยันจะคงข้อมูลเดิม; ผลยืนยันอยู่ในฟอร์มจนกดบันทึก

หากต้องการอ่านหน้าเดิมใหม่ เปิดเครื่องมืออ่านPDF เลือกไฟล์และหน้านั้น เลือก **รับหน้านี้ใหม่ในชุดเดิม** ระบุฐานจำนวนเดิมและบันทึกที่มา ตรวจตัวเลข/หน่วย/รูปดัดพร้อมยืนยันล้างการจับคู่ แล้วรับและบันทึก หน้าอื่นและID/กรอบรูปของหน้าอื่นคงไว้ ส่วนรายการหน้าที่รับใหม่มีIDใหม่และรูปที่อ่านใหม่ ไม่อนุมานว่ากรอบที่เคยปรับด้วยมือนั้นผ่านการตรวจแล้ว

การเพิ่ม/รับหน้าใหม่จำกัดไฟล์ attachment/SHA256และฐานจำนวนเดียวกัน Markซ้ำกับหน้าอื่นถูกปฏิเสธ ไม่รวมจำนวนให้อัตโนมัติ สูงสุด300รายการ/20หน้า การแก้บันทึก/Total ลบหน้า หรือรับหน้าใหม่ล้างการจับคู่BBSทั้งชุดเพื่อทบทวน ส่วนเหล็กBBSจริงยังเก็บไว้ให้ตรวจและจับคู่ใหม่ จำนวนองค์ประกอบ เรขาคณิต และสูตรBOQไม่เปลี่ยนจากการแก้ตารางอ้างอิง

คำยืนยันผูกกับสมาชิก รุ่น และข้อมูลตารางปัจจุบัน การเปลี่ยนข้อมูลหรือสิทธิ์อ่านอย่างเดียวจะปิดแบบแก้ที่เปิดอยู่ ระบบใช้สิทธิ์เดิมของโครงการ ไม่มีสิทธิ์พิเศษจากเครื่องมือจัดการหน้า Legacyตารางรุ่น1/2อ่านได้; ชุดหลายหน้าใช้รุ่น3 และอาจกลับเป็นรุ่น2เมื่อเหลือหน้าเดียว ต้องใช้clientรุ่นที่รองรับข้อมูลนั้น

Excel/PDFเก็บทะเบียนหน้าต้นทาง Total/บันทึกและหน้าของแต่ละแถวตามข้อมูลFrozenที่เลือก Backup/Restoreเก็บข้อมูลชุดที่แก้ โดยเปลี่ยนattachmentIDตามปลายทางและคงSHA256/รูปต้นฉบับ ตรวจผลรวมแถวกับTotalแต่ละหน้า ไม่มีการเติมส่วนต่างหรือกำหนดtoleranceแทนผู้รับผิดชอบ

ชุดทดสอบใช้B104หน้า2/19เป็นข้อมูลอ้างอิง55รายการ และสมาชิกกล่องชั่วคราวที่ยังเป็นProvisional ไม่ใช่เรขาคณิตหรือBBSจริงจากGULF การทดสอบเหล็กเดี่ยวเป็นข้อมูลซอฟต์แวร์แยกต่างหาก ไม่ใช่การเทียบSD40กับBSโดยอัตโนมัติ ต้องตรวจและรับรองกฎBS8666/ACI318 รูปดัด/ตำแหน่ง และชุดส่งเจ้าของงานก่อนก่อสร้าง
