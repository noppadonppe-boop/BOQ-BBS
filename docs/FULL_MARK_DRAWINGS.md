# ภาพเหล็กครบทุก Mark ใน BBS — v0.88

แบบแปลนและรูปตัดที่สร้างจากข้อมูลสมาชิกแสดงตำแหน่งเหล็กครบทุก Mark ของสมาชิกในทุกกลุ่มตาราง แม้ตารางแบ่งหลายหน้า

- สีเขียว: เหล็กของกลุ่มตารางหน้านั้น พร้อมเส้นชี้ชื่อ Mark
- สีเทา: เหล็ก Mark อื่นที่อยู่ร่วมกัน ใช้ประกอบการอ่านตำแหน่ง
- ชื่อ `(no intersection)`: Mark ในกลุ่มตารางที่ไม่ผ่านแนวรูปตัด ไม่มีเส้นชี้ไปยังตำแหน่งเทียม

รูปตัดแสดงเฉพาะเหล็กที่ผ่านแนวตัดจริง ไม่ฉายเหล็กที่อยู่นอกแนวเข้ามา ปริมาณในตารางต่อหนึ่งองค์ประกอบและจำนวนองค์ประกอบไม่เปลี่ยนจากการแบ่งหน้า แบบหลายรูปตัดใช้รายการ BBS เดียวกัน ห้ามรวมปริมาณซ้ำจากแต่ละรูป

ปรับระยะห่างชื่อ Mark ให้ใช้พื้นที่ภาพได้มากขึ้น ชื่อยาวตัดบรรทัดตามพื้นที่ และมีคำอธิบายสีใต้ภาพเหนือหัวตาราง ใช้ร่วมกันในรูปแบบส่งออกที่มีภาพแปลน/รูปตัด รวมทั้งตาราง BBS และแบบพร้อมมิติ

ข้อมูลตำแหน่งทั้งหมดมาจากสมาชิกที่บันทึกไว้ ความครบของภาพไม่ได้รับรองว่าตำแหน่งนั้นตรงแบบโครงการหรือผ่านข้อกำหนดทางวิศวกรรม ยังต้องตรวจตำแหน่ง Mark กับแปลน/รูปตัดต้นทางและอนุมัติก่อนส่งใช้ก่อสร้าง
