# ผลวัดเหล็กที่ผลิตจริงรายชิ้น — v0.37

เปิดสมาชิกและเลือก Mark เพื่อดู **ผลวัดเหล็กที่ผลิตจริงรายชิ้น** หรือเปิดหน้าต่างแก้ชุดเหล็กเพื่อเพิ่มผล ระบุรหัสชิ้น/ตัวอย่าง วันที่ ผู้บันทึก และเอกสาร/รายงานอ้างอิง กรอกความยาวตัดที่วัดจริง ส่วนมิติดัดและรัศมีกรอกได้ตามผลวัดที่มี ช่องผลวัดเริ่มว่าง ไม่แทนค่ากำหนดให้โดยอัตโนมัติ เพิ่มผลแล้วใช้ชุดเหล็กและบันทึกสมาชิก ข้อมูลกลับ Draft และล้างการยืนยันมิติ/ตำแหน่งตามกระบวนการเดิม

แต่ละ Mark เก็บได้20ชิ้น รหัสชิ้นห้ามซ้ำใน Mark เดียวกันแม้เปลี่ยนตัวพิมพ์ รหัสชิ้น/ผู้บันทึก80ตัวอักษร อ้างอิง/หมายเหตุ500ตัวอักษร ผลวัดต้องเป็นบวก finite และไม่เกิน200,000mm วันที่ต้องเป็นวันจริงในรูป YYYY-MM-DD ช่องมิติที่ไม่วัดยังว่าง; บันทึกข้อมูลไม่ครบและผลนอกช่วงได้เพื่อเก็บหลักฐาน ไม่แทนด้วย0หรือถือว่าผ่าน บัญชีที่มีสิทธิ์แก้สมาชิกเท่านั้นเพิ่ม/ลบผล Workingได้ Viewerอ่านได้ บทบาทผู้บันทึกเป็นชื่อที่ผู้ใช้กรอก ไม่ใช่ลายเซ็นหรือการยืนยันตัวตนของผู้ตรวจ

แหล่งช่วงอ้างอิงคือ BS8666:2000+Amd1/2 ที่ผู้ใช้ให้ไว้ `Referrence/BS 8666.pdf` ข้อ9/Table4 หน้า13 (PDF17), SHA256 `9c6fa5d0bafd0a8761f14d1611c582d5db7d89710eaaf0910b5dc7c493e0cb43` ใช้ช่วงตัด±25mm และมิติดัด+5/−5,−10,−25mmตามขนาดมิติเดิม ไม่เปลี่ยนรุ่นกฎตัวเลขหรือใช้มาตรฐานใหม่โดยอัตโนมัติ รองรับเฉพาะมิติที่ตัวคำนวณของ Snapshotจับคู่ geometryกับรูปมาตรฐานได้ รัศมีไม่ถูกกำหนด tolerance Table4ให้อัตโนมัติ

ผลมี4สถานะ: **Within listed ranges** สำหรับช่วงรายมิติที่วัดครบ, **Outside listed limits** เมื่อค่านอกช่วงหรือปลาย/รัศมีต่ำกว่า Table3ที่ตรวจได้, **Incomplete** เมื่อขาดผลหรือมิติยังไม่จับคู่, และ **Stale nominal** เมื่อมิติกำหนดเปลี่ยน การผ่านช่วงรายมิติยังไม่ตรวจครบทุกเงื่อนไขปลาย ช่วงดัด รูปผลิตจริง วัสดุ ลำดับผลิต/เท การตรวจทั้งล็อต หรือ ACI ไม่เปิด Issuedหรือการใช้ stock Production

ผลแต่ละชิ้นเก็บชุดมิติกำหนดพร้อมข้อมูลวิธีคำนวณไว้ เปลี่ยนมิติ/แนว/รัศมี/วัสดุ/ขนาด/Mark/ยาวตัด/นโยบายที่เกี่ยวข้องแล้วผลเก่าจะแสดงว่าต้องตรวจใหม่ โดยเก็บข้อมูลเดิมไว้ การเปลี่ยนจำนวนชิ้นไม่ทำให้ผลวัดหนึ่งชิ้นกลายเป็นผลตรวจทั้งหมด ชุดมิติกำหนดที่เก็บเป็นข้อมูลอ้างอิงสำหรับเทียบ ไม่ใช่ hashรับรองผู้ตรวจหรือเอกสารต้นทาง ผล Frozenและประวัติที่นำกลับอ่านได้ตรงข้อมูลเดิม

สมการเทียบมิติอิสระใช้เฉพาะ11/12/13/21/31/41/44ที่จับคู่ได้: แทนยาวตัด มิติตัวอื่น และรัศมีด้านในที่วัดจริงในสมการ Table1เพื่อหามิติอิสระที่ต้องการ แล้วแสดงผลวัดลบค่าที่ต้องการ สำหรับ13ใช้ `A+0.57B+C−1.57d` และไม่ใช้รัศมีเป็นตัวแปรแทนB ขาดค่าที่ต้องใช้แล้วไม่สร้างผลแทน ไม่รวมการเปลี่ยนรัศมี/ซี่บั้งเป็นค่าเผื่อที่สมมุติ ไม่มีช่วงยอมรับผลต่างสูตรที่ได้รับอนุมัติ ไม่รวม worst-case stackของตัวแปรอิสระ ไม่ปรับ geometry/ยาวตัด/น้ำหนักอัตโนมัติ และยังไม่ปิดการตรวจรับข้อ9ทั้งข้อ ต้องกำหนดการรับค่าคลาดเคลื่อนร่วมกับวิศวกรและผู้ผลิต

Excelใหม่เพิ่ม **Fabrication Checks** เมื่อมีผลวัด วันที่เป็นค่า Dateจริง คอลัมน์ **Range comparison (Excel)** เชื่อมผลวัดกับขอบล่าง/บนและคำนวณซ้ำได้เมื่อแก้สำเนา Excel ส่วน **App status at export**, ขอบเขตที่ส่งออก และมิติอิสระ/ผลต่างที่ระบุ captured เป็นข้อมูลขณะส่งออก ต้องกลับแอปเพื่อตรวจครบ ไม่ใช้ชีตนี้แก้ geometryหรือ BOQ แสดงมิติปัจจุบันและมิติกำหนดที่เก็บพร้อมผลวัดแยกกัน ตั้งกระดาษA3/scale100และซ้ำหัว/รหัสชิ้นเมื่อพิมพ์ ไม่ย่อตารางกว้างทั้งหมดลงหน้าเดียว; การพิมพ์ในExcelจริงยังไม่ได้ตรวจรับ

PDFตาราง A4เพิ่มผลวัดรายชิ้นเป็นภาคผนวก แสดงชื่อชิ้นและอ้างอิงเต็มความกว้าง และเปรียบเทียบตัวเลขในตาราง ไม่พิมพ์รหัสยาวซ้ำทุกแถว กรณีที่รองรับตามทดสอบแยกหนึ่งชิ้นต่อหน้า มีข้อจำกัดรวม500หน้าและปฏิเสธหัวที่ยาวเกินพื้นที่แทนตัดข้อมูลทิ้ง ทุกหน้าเป็น USER RECORDED / NOT FOR CONSTRUCTION ไม่แทนBBSแบบ A3/A1หรือการตรวจรับเจ้าของงาน
