# ปรับตำแหน่งและจำนวนเป็นชุด

ใน **ทะเบียนสมาชิก** เลือกตำแหน่งรายแถว เลือกทั้งหน้า หรือเลือกทั้งหมดที่ค้นพบข้ามทุกหน้า แล้วเปิด **ปรับตำแหน่ง/จำนวนที่เลือก** ตัวกรอง Member/ประเภท/Zone/ชั้น การค้นหา และสถานะ จำกัดผลที่เลือก การเปลี่ยนตัวกรองหรือรุ่นโครงการล้างการเลือกทันที ปุ่มย้ายชื่อ Zone/ชั้นทั้งโครงการยังเป็นคนละงานและยังใช้ทั้งโครงการตามเดิม

เลือกเฉพาะช่องที่ต้องการปรับ Zone/ชั้น/Grid หรือใช้จำนวนเดียวกันทุกตำแหน่งที่เลือก ช่องข้อความที่เลือกและปล่อยว่างหมายถึงไม่ระบุ ช่องที่ไม่เลือกคงค่าเดิม จำนวนต้องเป็นจำนวนเต็ม1–100000 ระบุเหตุผลก่อนตรวจตัวอย่างสมาชิก/ตำแหน่ง/จำนวนและปริมาณก่อน–หลัง ตัวอย่างแสดงเฉพาะแถวที่เปลี่ยนจริง พร้อมแบ่งหน้า20แถว ไม่รวม occurrence ที่มีชื่อพื้นที่เหมือนกันเข้าด้วยกัน

เมื่อเริ่ม ระบบเก็บ manifest ก่อน–หลังที่ตรวจ checksum แล้วล็อกโครงการ ใช้ชุดละไม่เกิน25สมาชิก/4MiB ทำต่อหลังปิดหรือ reload ได้ และยกเลิกเพื่อคืนข้อมูลเดิมพร้อม version ของสมาชิกที่ปรับไปแล้ว โครงการเผยแพร่ version ใหม่ครั้งเดียวเมื่อครบทุกสมาชิก แถบความคืบหน้าและประวัติรายการอยู่ในทะเบียน

สมาชิกที่เปลี่ยนกลับ Draft และล้างการยืนยันตำแหน่งเหล็ก คำยืนยันไม่มีเหล็กที่ขอบเขตเปลี่ยนถูกล้าง มิติ/เรขาคณิตและจำนวนต่อMarkคงเดิม ปริมาณ BBS ต่อสมาชิกคูณจำนวนองค์ประกอบครั้งเดียว ฉบับFrozenเดิมคงเดิม ต้องตรวจเอกสารต้นทางและการจัดวางก่อนตรวจรับใหม่

ผู้ดูแล/QS ที่มีสิทธิ์ในโครงการเริ่มและทำต่อได้ Viewer อ่านอย่างเดียว จำนวนเลือกสูงสุด10000ตำแหน่ง โครงการสูงสุด5000สมาชิก manifestสูงสุด40MiB และเงื่อนไขขนาดเอกสารเดิมยังใช้ ขีดจำกัดเหล่านี้ไม่ใช่ผลรับรอง load5000สมาชิก การทดสอบรอบนี้ใช้57สมาชิก งานที่มีสต็อกจองหรือ export lease ที่ยังใช้งานอยู่เริ่มไม่ได้ รหัสคำขอเดิม replay ได้โดยไม่สร้างชุดซ้ำ แต่เปลี่ยนข้อมูลภายใต้รหัสเดิมถูกปฏิเสธ

Backup เก็บงานและ manifest เป็นประวัติ Restore เก็บไฟล์ตามhashเดิม สมาชิกกลับDraftและไม่เปิด active jobs/approvals/Issued ที่นำเข้า สิทธิ์ของโครงการปลายทางคงตามปลายทาง

ใช้ Firestore/Storage paths และ pipeline ของ project-change เดิม ไม่มี Cloud Functions หรือการเปลี่ยน/deploy Rules การตรวจclientและ transaction ไม่แทนการบังคับนโยบายผ่าน API/Rules ฝั่งเซิร์ฟเวอร์ที่ผู้ใช้จัดการเอง ผลนี้เป็นความสามารถจัดข้อมูล ไม่เป็นการตรวจรับ BS/ACI/GULF/การผลิต/Issued หรือ Production
